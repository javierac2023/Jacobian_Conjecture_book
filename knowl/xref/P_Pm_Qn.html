Remark 1.2.11. .

Let \(P\) and \(Q\) in \(K[x,y]\text{.}\) From items 1 and 5 of Lemma Lemma 1.2.10 it follow that
🔗
\begin{equation*} [P, P^m] = m P^{m-1}[P,P] = 0 \quad\text{and}\quad [P, Q^n] = n Q^{n-1}[P,Q] \qquad\text{for all } m,n\in \mathbb{N}. \end{equation*}
Hence, by item 4 of Lemma Lemma 1.2.10,
🔗
\begin{equation*} [P, P^m Q^n] = [P,P^m] Q^n + P^m [P, Q^n] = P^m [P, Q^n] = \begin{cases} n P^m Q^{n-1}[P,Q] & \text{if } n>0, \\ 0 & \text{if } n=0. \end{cases} \end{equation*}
Using this it follows easily that if \([P,Q]\in K^{\times}\text{,}\) then the set \(\{P^i Q^j : i,j\in \mathbb{N}_0\}\) is \(K\)-linearly independent.
