Remark 1.4.7.

Let \(P,Q \in K[x,y]\setminus\{0\}\) and \((\rho,\sigma) \in \mathfrak{V}\text{.}\) The following assertions hold:
🔗
  1. \(\ell_{\rho\sigma}(PQ) = \ell_{\rho\sigma}(P) \ell_{\rho\sigma}(Q)\text{.}\)
    🔗
  2. Let \(P = \sum_i P_i\text{.}\) If there exists \(\tau \in \mathbb{Z}\) such that \(v_{\rho\sigma}(P_i) = \tau\text{,}\) for all \(i\text{,}\) and \(\sum_i \ell_{\rho\sigma}(P_i) \ne 0\text{,}\) then
    \begin{equation*} \ell_{\rho\sigma}(P) = \sum_i \ell_{\rho\sigma}(P_i) \quad\text{and}\quad v_{\rho\sigma}(P) = \tau. \end{equation*}
    🔗
    🔗
  3. If \(P = P_1 + P_2 + \cdots + P_r\) and \(v_{\rho\sigma}(P_1) > v_{\rho\sigma}(P_2) > \cdots\text{,}\) then \(\ell_{\rho\sigma}(P) = \ell_{\rho\sigma}(P_1)\text{.}\)
    🔗
    🔗
  4. \(v_{\rho\sigma}(PQ) = v_{\rho\sigma}(P) + v_{\rho\sigma}(Q)\text{.}\)
    🔗
  5. \(-v_{-\rho,-\sigma}(P) \le v_{\rho\sigma}(P)\text{.}\)
    🔗
Frequently, we will use these facts throughout the book without explicit mention.
