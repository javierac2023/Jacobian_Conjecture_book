Proposition 1.4.23.

Let \((\rho,\sigma) \in \mathfrak{V}\) and let \(P,Q,R \in K[x,y]\setminus \{0\}\) be such that
\begin{equation*} [\ell_{\rho\sigma}(P), \ell_{\rho\sigma}(Q)] = \ell_{\rho\sigma}(R). \end{equation*}
The following assertions hold:
🔗
  1. \(\operatorname{stn}_{\rho\sigma}(P) \times \operatorname{stn}_{\rho\sigma}(Q) \ne 0\) if and only if \(\operatorname{stn}_{\rho\sigma}(P) + \operatorname{stn}_{\rho\sigma}(Q) - (1,1) = \operatorname{stn}_{\rho\sigma}(R)\text{.}\)
    🔗
    🔗
  2. \(\operatorname{en}_{\rho\sigma}(P) \times \operatorname{en}_{\rho\sigma}(Q) \ne 0\) if and only if \(\operatorname{en}_{\rho\sigma}(P) + \operatorname{en}_{\rho\sigma}(Q) - (1,1) = \operatorname{en}_{\rho\sigma}(R)\text{.}\)

    🔗
