    Section 1.4 Directions, leading terms, starting points and end points

    We denote by \(\mathfrak{V}\) the set of all directions in \(\mathbb{Z}^2\text{,}\) which by definition is the set of all \((\rho,\sigma)\in \mathbb{Z}^2\setminus \{(0,0)\}\) such that \(\gcd(\rho,\sigma) = 1\text{.}\) We also denote by \(\mathfrak{V}_{\ge 0}\) and \(\mathfrak{V}_{>0}\text{,}\) the sets
    \begin{equation*} \mathfrak{V}_{\ge 0} := \{(\rho,\sigma)\in \mathfrak{V} : \rho+\sigma \ge 0\} \quad\text{and}\quad \mathfrak{V}_{>0} := \{(\rho,\sigma)\in \mathfrak{V} : \rho+\sigma > 0\}, \end{equation*}
    of non negative and positive directions, respectively.
    🔗

    Definition 1.4.1.

    For all \((\rho,\sigma)\in \mathfrak{V}\) and \((i,j)\in \mathbb{N}_0 \times \mathbb{N}_0\text{,}\) we write \(v_{\rho\sigma}(i,j) := \rho i + \sigma j\text{.}\)
    🔗
    🔗

    Definition 1.4.2.

    Let \((\rho,\sigma)\in \mathfrak{V}\text{.}\) For \(P := \sum a_{ij} x^i y^j \in K[x,y]\setminus\{0\}\text{,}\) we define:
    🔗
    • The \((\rho,\sigma)\)-degree of \(P\) as \(v_{\rho\sigma}(P) := \max\{ v_{\rho\sigma}(i,j) : a_{ij} \ne 0\}\text{.}\)
      🔗
      🔗
    • The \((\rho,\sigma)\)-leading term of \(P\) as \(\ell_{\rho\sigma}(P) := \displaystyle \sum_{\rho i+\sigma j = v_{\rho\sigma}(P)} a_{ij} x^i y^j\text{.}\)
      🔗
      🔗
    Note that the usual total degree of \(P\) is \(\deg(P) := v_{11}(P)\text{.}\)
    🔗
    🔗

    Note 1.4.3.

    To abbreviate expressions we set \(v_{\rho\sigma}(0) := -\infty\) and \(\ell_{\rho\sigma}(0) := 0\text{,}\) for all \((\rho,\sigma)\in \mathfrak{V}\text{.}\)
    🔗
    🔗
    In Figure 1.4.4 are drawn \(\ell_{\rho\sigma}(P)\text{,}\) \(\ell_{\rho\sigma}(Q)\) and \(\ell_{\rho\sigma}(PQ)\) for some directions \((\rho,\sigma)\) and
    \begin{equation*} (P,Q) = (x^3y + x^2y^2 + xy^2 + x^2 + y + 2,\; 4xy^2 - y^2 + 2x - 1). \end{equation*}
    The representation of \(\ell_{\rho\sigma}(PQ)\) illustrates Remark 1.4.9 (1).
    🔗

    Definition 1.4.7.

    We say that \(P \in K[x,y]\) is \((\rho,\sigma)\)-homogeneous if \(P = \ell_{\rho\sigma}(P)\text{.}\)
    🔗
    🔗

    Remark 1.4.8.

    Since
    \begin{equation*} \rho x \frac{\partial x^i y^j}{\partial x} + \sigma y \frac{\partial x^i y^j}{\partial y} = (\rho i + \sigma j) x^i y^j = v_{\rho\sigma}(x^i y^j) x^i y^j, \end{equation*}
    a polynomial \(P \ne 0\) is \((\rho,\sigma)\)-homogeneous with \(v_{\rho\sigma}(P) = \tau\) if and only if \(\rho x P_x + \sigma y P_y = \tau P\text{.}\)
    🔗
    🔗
    For all \(P \in K[x,y] \setminus \{0\}\text{,}\) each one of the edges of \(\operatorname{HN}(P)\) is the convex hull of the support of \(\ell_{\rho\sigma}(P)\text{,}\) where \((\rho,\sigma)\) is orthogonal to the given edge and points outside of \(\operatorname{HN}(P)\text{.}\)
    🔗

    Remark 1.4.9.

    Let \(P,Q \in K[x,y]\setminus\{0\}\) and \((\rho,\sigma) \in \mathfrak{V}\text{.}\) The following assertions hold:
    🔗
    1. \(\ell_{\rho\sigma}(PQ) = \ell_{\rho\sigma}(P) \ell_{\rho\sigma}(Q)\text{.}\)
      🔗
    2. Let \(P = \sum_i P_i\text{.}\) If there exists \(\tau \in \mathbb{Z}\) such that \(v_{\rho\sigma}(P_i) = \tau\text{,}\) for all \(i\text{,}\) and \(\sum_i \ell_{\rho\sigma}(P_i) \ne 0\text{,}\) then
      \begin{equation*} \ell_{\rho\sigma}(P) = \sum_i \ell_{\rho\sigma}(P_i) \quad\text{and}\quad v_{\rho\sigma}(P) = \tau. \end{equation*}
      🔗
      🔗
    3. If \(P = P_1 + P_2 + \cdots + P_r\) and \(v_{\rho\sigma}(P_1) > v_{\rho\sigma}(P_2) > \cdots\text{,}\) then \(\ell_{\rho\sigma}(P) = \ell_{\rho\sigma}(P_1)\text{.}\)
      🔗
      🔗
    4. \(v_{\rho\sigma}(PQ) = v_{\rho\sigma}(P) + v_{\rho\sigma}(Q)\text{.}\)
      🔗
    5. \(-v_{-\rho,-\sigma}(P) \le v_{\rho\sigma}(P)\text{.}\)
      🔗
    Frequently, we will use these facts throughout the book without explicit mention.
    🔗
    🔗

    Proposition 1.4.10.

    The identity \(\operatorname{HN}(PQ) = \operatorname{HN}(P) + \operatorname{HN}(Q)\) holds for each \(P,Q \in K[x,y]\setminus\{0\}\text{.}\)
    🔗
    🔗

    Proof.
    For each direction \((\rho,\sigma)\text{,}\) let \(s_{\rho\sigma}(PQ) := \{(i,j) \in \mathbb{Z}^2 : v_{\rho\sigma}(i,j) \le v_{\rho\sigma}(PQ)\}\text{.}\) By the discussion below Definition 1.1.11, we know that \(\operatorname{HN}(PQ) \subseteq \operatorname{HN}(P) + \operatorname{HN}(Q)\text{.}\) The opposite inclusion follows from the fact that \(\operatorname{HN}(PQ) = \bigcap_{(\rho,\sigma)\in \mathfrak{V}} s_{\rho\sigma}(PQ)\) and \(\operatorname{HN}(P) + \operatorname{HN}(Q) \subseteq s_{\rho\sigma}(PQ)\) by Remark 1.4.9(4).
    🔗
    🔗
    Let \(P \in K[x,y]\) and let \((\rho,\sigma) \in \mathfrak{V}\text{.}\) We say that \(P = \sum_i P_i\) is the \((\rho,\sigma)\)-homogeneous decomposition of \(P\) if \(v_{\rho\sigma}(P_i) = i\text{,}\) for all \(P_i \ne 0\text{.}\)
    🔗

    Remark 1.4.11.

    Let \(P,Q \in K[x,y]\setminus\{0\}\) and let \((\rho,\sigma) \in \mathfrak{V}\text{.}\) We have:
    🔗
    1. If \(P\) and \(Q\) are \((\rho,\sigma)\)-homogeneous, then \([P,Q]\) is also. Moreover, if \([P,Q] \ne 0\text{,}\) then
      \begin{equation*} v_{\rho\sigma}([P,Q]) = v_{\rho\sigma}(P) + v_{\rho\sigma}(Q) - (\rho+\sigma). \end{equation*}
      🔗
      🔗
    2. If \(P = \sum_i P_i\) and \(Q = \sum_j Q_j\) are the \((\rho,\sigma)\)-homogeneous decompositions of \(P\) and \(Q\text{,}\) then the \((\rho,\sigma)\)-homogeneous decomposition \([P,Q] = \sum_k [P,Q]_k\) is given by
      \begin{equation} [P,Q]_k = \sum_{i+j = k + \rho + \sigma} [P_i, Q_j].\tag{1.4.1} \end{equation}
      🔗
      🔗
    3. If \([P,Q] = 0\text{,}\) then \([\ell_{\rho\sigma}(P), \ell_{\rho\sigma}(Q)] = 0\text{.}\)
      🔗
      🔗
    🔗

    Proposition 1.4.12.

    Let \(P,Q \in K[x,y]\setminus \{0\}\text{.}\) Then
    \begin{equation*} v_{\rho\sigma}([P,Q]) \le v_{\rho\sigma}(P) + v_{\rho\sigma}(Q) - (\rho+\sigma), \end{equation*}
    for each \((\rho,\sigma) \in \mathfrak{V}\text{.}\) Moreover,
    \begin{equation*} v_{\rho\sigma}([P,Q]) = v_{\rho\sigma}(P) + v_{\rho\sigma}(Q) - (\rho+\sigma) \iff [\ell_{\rho\sigma}(P), \ell_{\rho\sigma}(Q)] \ne 0, \end{equation*}
    and, in this case, \([\ell_{\rho\sigma}(P), \ell_{\rho\sigma}(Q)] = \ell_{\rho\sigma}([P,Q])\text{.}\)
    🔗
    🔗

    Proof.
    It follows directly from the decomposition (1.4.1).
    🔗
    🔗

    Note 1.4.13.

    Let \((\rho,\sigma) \in \mathfrak{V}\) arbitrary and let \(P \in K[x,y]\setminus \{0\}\text{.}\) We let \(\operatorname{stn}_{\rho\sigma}(P)\) and \(\operatorname{en}_{\rho\sigma}(P)\) denote the first and the last point that we find on \(H(\ell_{\rho\sigma}(P))\) when we run counterclockwise along the boundary of \(H(P)\text{.}\) The identities in (1.4.2) can be taken as a formal definition of the starting point \(\operatorname{stn}_{\rho\sigma}(P)\) and the end point \(\operatorname{en}_{\rho\sigma}(P)\) of \(\ell_{\rho\sigma}(P)\text{.}\) Note that these points coincide if and only if \(\ell_{\rho\sigma}(P)\) is a monomial.
    🔗
    🔗

    Remark 1.4.14.

    The identities
    \begin{equation*} \operatorname{stn}_{\rho\sigma}(PQ) = \operatorname{stn}_{\rho\sigma}(P) + \operatorname{stn}_{\rho\sigma}(Q) \quad\text{and}\quad \operatorname{en}_{\rho\sigma}(PQ) = \operatorname{en}_{\rho\sigma}(P) + \operatorname{en}_{\rho\sigma}(Q) \end{equation*}
    hold for each \(P,Q \in K[x,y]\setminus\{0\}\) and \((\rho,\sigma) \in \mathfrak{V}\text{.}\) Moreover, we have
    \begin{equation} \operatorname{stn}_{\rho\sigma}(P) = \operatorname{Supp}(\ell_{\sigma,-\rho}(\ell_{\rho\sigma}(P))) \quad\text{and}\quad \operatorname{en}_{\rho\sigma}(P) = \operatorname{Supp}(\ell_{-\sigma,\rho}(\ell_{\rho\sigma}(P))),\tag{1.4.2} \end{equation}
    as is illustrated in Figure 1.4.15.
    🔗
    🔗

    Remark 1.4.16.

    Let \(P \in K[x,y]\text{,}\) \((\rho,\sigma) \in \mathfrak{V}\) and let \(\tau := \varphi_{y,x}\) be the automorphism of \(K[x,y]\) that interchanges \(x\) and \(y\text{.}\) A direct computation shows that \(\ell_{\rho\sigma}(\tau(P)) = \tau(\ell_{\sigma\rho}(P))\text{.}\) From this and equalities (1.4.2) it follows that \(\operatorname{stn}_{\rho\sigma}(\tau(P)) = \overline{\tau}(\operatorname{en}_{\sigma\rho}(P))\) and \(\operatorname{en}_{\rho\sigma}(\tau(P)) = \overline{\tau}(\operatorname{stn}_{\sigma\rho}(P))\text{,}\) where \(\overline{\tau}\) denotes the flip of \(\mathbb{R}^2\text{.}\)
    🔗
    🔗
    The cross product of two vectors \(A = (a_1,a_2)\) and \(B = (b_1,b_2)\) in \(\mathbb{R}^2\) is \(A \times B := \det\begin{pmatrix} a_1 & a_2 \\ b_1 & b_2 \end{pmatrix}\text{.}\)
    🔗

    Remark 1.4.17.

    If \(\ell_{\rho\sigma}(P)\) is not a monomial, then \((\rho,\sigma) \times (\operatorname{en}_{\rho\sigma}(P) - \operatorname{stn}_{\rho\sigma}(P)) > 0\text{.}\)
    🔗
    🔗

    Remark 1.4.18.

    Let \(P \in K[x,y]\setminus\{0\}\) and \((\rho,\sigma) \in \mathfrak{V}\text{.}\) Set \(z := x^{-\sigma} y^{\rho} \in K[x,y,x^{-1},y^{-1}]\) and write
    \begin{equation*} \ell_{\rho\sigma}(P) = x^r y^s p(z), \end{equation*}
    where \(p := \sum_{i=0}^{\gamma} a_i z^i \in K[z]\) with \(a_0 \ne 0\) and \(a_{\gamma} \ne 0\text{.}\) Since \(v_{\sigma,-\rho}(z) = -\rho^2 - \sigma^2 < 0\text{,}\) by (1.4.2) we have
    \begin{equation} \operatorname{stn}_{\rho\sigma}(P) = (r,s) \quad\text{and}\quad \operatorname{en}_{\rho\sigma}(P) = (r - \gamma\sigma,\; s + \gamma\rho).\tag{1.4.3} \end{equation}
    🔗
    🔗

    Definition 1.4.19.

    For two vectors \(A,B\) in any \(K\)-vector space, we write \(A \sim B\text{,}\) if there exists \(\lambda \in K^{\times}\) such that \(A = \lambda B\text{.}\) In this case we say that \(A\) and \(B\) are aligned .
    🔗
    🔗

    Remark 1.4.20.

    Note that, for \(A,B \in \mathbb{R}^2\text{,}\)
    \begin{equation*} A \times B = 0 \iff A = 0,\; B = 0 \text{ or } A \sim B. \end{equation*}
    So,
    \begin{equation*} A \sim B \iff A = B = 0,\; \text{or } A \ne 0,\; B \ne 0 \text{ and } A \times B = 0. \end{equation*}
    🔗
    🔗

    Remark 1.4.21.

    If \(P,Q \in K[x,y]\text{,}\) then \([P,Q] \sim 1\) means that \([P,Q] \in K^{\times}\text{,}\) and so \((P,Q)\) is a Jacobian pair.
    🔗
    🔗

    Proposition 1.4.22.

    Let \(P,Q \in K[x,y]\setminus \{0\}\) and \((\rho,\sigma) \in \mathfrak{V}\text{.}\) If \([\ell_{\rho\sigma}(P), \ell_{\rho\sigma}(Q)] = 0\text{,}\) then
    \begin{equation*} \operatorname{stn}_{\rho\sigma}(P) \times \operatorname{stn}_{\rho\sigma}(Q) = 0 \quad\text{and}\quad \operatorname{en}_{\rho\sigma}(P) \times \operatorname{en}_{\rho\sigma}(Q) = 0. \end{equation*}
    🔗
    🔗

    Proof.
    Write \((r,s) := \operatorname{stn}_{\rho\sigma}(P)\) and \((u,v) := \operatorname{stn}_{\rho\sigma}(Q)\text{.}\) By identities (1.4.2) there exist \(\lambda_p, \lambda_q \in K^{\times}\) such that
    \begin{equation*} \ell_{\sigma,-\rho}(\ell_{\rho\sigma}(P)) = \lambda_p x^r y^s \quad\text{and}\quad \ell_{\sigma,-\rho}(\ell_{\rho\sigma}(Q)) = \lambda_q x^u y^v. \end{equation*}
    Hence, by Remark 1.4.11(3),
    \begin{equation*} (rv - su) \lambda_p \lambda_q x^{r+u-1} y^{s+v-1} = \bigl[\lambda_p x^r y^s, \lambda_q x^u y^v\bigr] = \bigl[\ell_{\sigma,-\rho}(\ell_{\rho\sigma}(P)), \ell_{\sigma,-\rho}(\ell_{\rho\sigma}(Q))\bigr] = 0. \end{equation*}
    Thus, \(\operatorname{stn}_{\rho\sigma}(P) \times \operatorname{stn}_{\rho\sigma}(Q) = rv - su = 0\text{.}\) A similar argument shows that \(\operatorname{en}_{\rho\sigma}(P) \times \operatorname{en}_{\rho\sigma}(Q) = 0\text{.}\)
    🔗
    🔗

    Proposition 1.4.23.

    Let \((\rho,\sigma) \in \mathfrak{V}\) and let \(P,Q,R \in K[x,y]\setminus \{0\}\) be such that
    \begin{equation*} [\ell_{\rho\sigma}(P), \ell_{\rho\sigma}(Q)] = \ell_{\rho\sigma}(R). \end{equation*}
    The following assertions hold:
    🔗
    1. \(\operatorname{stn}_{\rho\sigma}(P) \times \operatorname{stn}_{\rho\sigma}(Q) \ne 0\) if and only if \(\operatorname{stn}_{\rho\sigma}(P) + \operatorname{stn}_{\rho\sigma}(Q) - (1,1) = \operatorname{stn}_{\rho\sigma}(R)\text{.}\)
      🔗
      🔗
    2. \(\operatorname{en}_{\rho\sigma}(P) \times \operatorname{en}_{\rho\sigma}(Q) \ne 0\) if and only if \(\operatorname{en}_{\rho\sigma}(P) + \operatorname{en}_{\rho\sigma}(Q) - (1,1) = \operatorname{en}_{\rho\sigma}(R)\text{.}\)
      🔗
      🔗
    🔗

    Proof.
    We only prove item 1, since item 2 is similar. By replacing \(P\text{,}\) \(Q\) and \(R\) by \(\ell_{\rho\sigma}(P)\text{,}\) \(\ell_{\rho\sigma}(Q)\) and \(\ell_{\rho\sigma}(R)\) respectively, we can assume that \(P\text{,}\) \(Q\) and \(R\) are \((\rho,\sigma)\)-homogeneous, and we do it. Let \((r,s) := \operatorname{stn}_{\rho\sigma}(P)\text{,}\) \((u,v) := \operatorname{stn}_{\rho\sigma}(Q)\) and \((m,n) := \operatorname{stn}_{\rho\sigma}(R)\text{.}\) By identity (1.4.2) there exist \(\lambda_P, \lambda_Q, \lambda_R \in K^{\times}\) such that
    \begin{equation} \ell_{\sigma,-\rho}(P) = \lambda_P x^r y^s,\quad \ell_{\sigma,-\rho}(Q) = \lambda_Q x^u y^v \quad\text{and}\quad \ell_{\sigma,-\rho}(R) = \lambda_R x^m y^n.\tag{1.4.4} \end{equation}
    Clearly
    \begin{equation*} [\ell_{\sigma,-\rho}(P), \ell_{\sigma,-\rho}(Q)] = (rv - su) \lambda_P \lambda_Q x^{r+u-1} y^{s+v-1}, \end{equation*}
    and hence,
    \begin{equation} \operatorname{stn}_{\rho\sigma}(P) \times \operatorname{stn}_{\rho\sigma}(Q) \ne 0 \iff [\ell_{\sigma,-\rho}(P), \ell_{\sigma,-\rho}(Q)] \ne 0.\tag{1.4.5} \end{equation}
    Consequently, by Proposition 1.4.12, if \(\operatorname{stn}_{\rho\sigma}(P) \times \operatorname{stn}_{\rho\sigma}(Q) \ne 0\text{,}\) then
    \begin{equation*} \lambda_R x^m y^n = \ell_{\sigma,-\rho}(R) = [\ell_{\sigma,-\rho}(P), \ell_{\sigma,-\rho}(Q)] = (rv - su) \lambda_P \lambda_Q x^{r+u-1} y^{s+v-1}, \end{equation*}
    which implies that
    \begin{equation*} \operatorname{stn}_{\rho\sigma}(P) + \operatorname{stn}_{\rho\sigma}(Q) - (1,1) = \operatorname{stn}_{\rho\sigma}(R), \end{equation*}
    as desired. Conversely, if the last equality holds, then, by the first identity in (1.4.2),
    \begin{equation*} v_{\sigma,-\rho}(P) + v_{\sigma,-\rho}(Q) - (\sigma - \rho) = v_{\sigma,-\rho}(R), \end{equation*}
    and so, again by Proposition 1.4.12,
    \begin{equation*} [\ell_{\sigma,-\rho}(P), \ell_{\sigma,-\rho}(Q)] \ne 0, \end{equation*}
    which by (1.4.5) implies that \(\operatorname{stn}_{\rho\sigma}(P) \times \operatorname{stn}_{\rho\sigma}(Q) \ne 0\text{.}\)
    🔗
    🔗

    Definition 1.4.24.

    Let \(\varphi\) be an injective endomorphism of \(K[x,y]\) and let \((\rho,\sigma) \in \mathfrak{V}\text{.}\) We say that \(\varphi\) is \((\rho,\sigma)\)-homogeneous if, for all \((\rho,\sigma)\)-homogeneous polynomial \(P\text{,}\)
    \begin{equation*} \varphi(P) \text{ is } (\rho,\sigma)\text{-homogeneous and } v_{\rho\sigma}(\varphi(P)) = v_{\rho\sigma}(P). \end{equation*}
    🔗
    🔗

    Remark 1.4.25.

    By Remark 1.4.9, an injective endomorphism \(\varphi\) of \(K[x,y]\) is \((\rho,\sigma)\)-homogeneous if and only if \(\varphi(x)\) and \(\varphi(y)\) are \((\rho,\sigma)\)-homogeneous, \(v_{\rho\sigma}(\varphi(x)) = \rho\) and \(v_{\rho\sigma}(\varphi(y)) = \sigma\text{.}\) From this it follows immediately that \(\varphi\) is \((\rho,\sigma)\)-homogeneous if and only if it is \((-\rho,-\sigma)\)-homogeneous.
    🔗
    🔗

    Example 1.4.26.

    For all \(k \in \mathbb{N}_0\) and \(\lambda \in K\text{,}\) the elementary automorphism \(\varphi_{x,y+\lambda x^k}\) is \((1,k)\)-homogeneous.
