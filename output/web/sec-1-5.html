    Section 1.5 The element F

    Proposition 1.5.1.

    Let \((\rho,\sigma)\in \mathfrak{V}\) and let \(P,Q\in K[x,y]\setminus\{0\}\) be two \((\rho,\sigma)\)-homogeneous elements. Set \(\tau := v_{\rho\sigma}(P)\) and \(\mu := v_{\rho\sigma}(Q)\text{.}\)
    🔗
    1. If \(\tau = \mu = 0\text{,}\) then \([P,Q] = 0\text{.}\)
      🔗
      🔗
    2. Assume that \((\mu,\tau) \ne (0,0)\) and let \(m,n \in \mathbb{Z}\) coprime such that \(n\tau = m\mu\text{.}\) If \([P,Q] = 0\text{,}\) then \(\mu\tau \ge 0\text{,}\) we can take \(n,m \ge 0\) and the following facts hold:
      🔗
      1. There exists \(\alpha \in K^{\times}\) such that \(P^n = \alpha Q^m\text{.}\)
        🔗
        🔗
      2. There exists a \((\rho,\sigma)\)-homogeneous polynomial \(R\text{,}\) such that \(P \sim R^m\) and \(Q \sim R^n\text{.}\)
        🔗
        🔗
      🔗
    🔗

    Proof.
    1. For \((i,j) \in \mathbb{N}_0^2\text{,}\) set \(\mathbb{N}_0(i,j) := \{\lambda (i,j) : \lambda \in \mathbb{N}_0\}\text{.}\) Since \(P\) and \(Q\) are \((\rho,\sigma)\)-homogeneous and \(\tau = \mu = 0\text{,}\) there exists \((i,j) \ne (0,0)\text{,}\) such that \(\operatorname{Supp}(P) \cup \operatorname{Supp}(Q) \subseteq \mathbb{N}_0(i,j)\text{.}\) So \(P,Q \in K[z]\text{,}\) where \(z := x^i y^j\text{.}\) From this and Lemma 1.2.17(1) it follows that \([P,Q] = 0\text{.}\)
    🔗
    2. To prove that \(\mu\tau \ge 0\text{,}\) we can assume that \(\mu \ne 0\) and \(\tau \ne 0\text{,}\) which implies that \(\operatorname{stn}_{\rho\sigma}(P) \ne (0,0)\) and \(\operatorname{stn}_{\rho\sigma}(Q) \ne (0,0)\text{.}\) By Proposition 1.4.22, we know that \(\operatorname{stn}_{\rho\sigma}(P) \times \operatorname{stn}_{\rho\sigma}(Q) = 0\text{.}\) So, there exists \(\lambda \ne 0\) such that \(\operatorname{stn}_{\rho\sigma}(Q) = \lambda \operatorname{stn}_{\rho\sigma}(P)\text{.}\) Since both, \(\operatorname{stn}_{\rho\sigma}(P)\) and \(\operatorname{stn}_{\rho\sigma}(Q)\) are in \(\mathbb{N}_0^2\text{,}\) necessarily \(\lambda > 0\text{.}\) Therefore, \(\mu\tau = \lambda\tau^2 > 0\) and we can take \(n,m \ge 0\text{.}\)
    🔗
    2a) By Remark 1.4.8, we have
    \begin{equation*} \tau P Q_y - \mu Q P_y = (\rho x P_x + \sigma y P_y) Q_y - (\rho x Q_x + \sigma y Q_y) P_y = \rho x (P_x Q_y - P_y Q_x) = \rho x [P,Q] = 0. \end{equation*}
    Consequently \(n Q P_y - m P Q_y = 0\text{.}\) Thus,
    \begin{equation*} \frac{\partial}{\partial y}\left(\frac{P^n}{Q^m}\right) = \frac{n P^{n-1} P_y Q^m - m Q^{m-1} Q_y P^n}{Q^{2m}} = \frac{P^{n-1} Q^{m-1}}{Q^{2m}} (n Q P_y - m P Q_y) = 0, \end{equation*}
    and similarly, \(\frac{\partial}{\partial x}\bigl(\frac{P^n}{Q^m}\bigr) = 0\text{.}\) Hence, \(\frac{P^n}{Q^m} = \alpha \in K^{\times}\text{,}\) from which \(P^n = \alpha Q^m\) follows.
    🔗
    2b) Set \((r,s) := \operatorname{stn}_{\rho\sigma}(P)\text{,}\) \((u,v) := \operatorname{stn}_{\rho\sigma}(Q)\) and \(z := x^{-\sigma} y^{\rho}\text{.}\) Since \(P\) and \(Q\) are \((\rho,\sigma)\)-homogeneous and \(v_{-\sigma,\rho}(z) = -\rho^2 - \sigma^2 < 0\text{,}\) it follows from (1.4.2), that
    \begin{equation} P = x^r y^s f(z) \quad\text{and}\quad Q = x^u y^v g(z),\tag{1.5.1} \end{equation}
    for some \(f(z), g(z) \in K[z]\) such that \(f(0) \ne 0\) and \(g(0) \ne 0\text{.}\) By statement 2a), there exists \(\alpha \in K^{\times}\) such that
    \begin{equation*} x^{nr} y^{ns} f^n(z) = P^n = \alpha Q^m = \alpha x^{mu} y^{mv} g^m(z), \end{equation*}
    which implies
    \begin{equation} (nr, ns) = (mu, mv) \quad\text{and}\quad f^n = \alpha g^m.\tag{1.5.2} \end{equation}
    Since \(\gcd(m,n) = 1\text{,}\) by the second equality there exists \(h \in K[z]\) such that
    \begin{equation} f \sim h^m \quad\text{and}\quad g \sim h^n.\tag{1.5.3} \end{equation}
    Take \(c,d \in \mathbb{Z}\) such that \(cm + dn = 1\) and define \(R(x,y) := x^a y^b h(z)\text{,}\) where \((a,b) := c(r,s) + d(u,v)\text{.}\) Since, by the first identity in (1.5.2),
    \begin{equation} m(a,b) = (r,s) \quad\text{and}\quad n(a,b) = (u,v),\tag{1.5.4} \end{equation}
    from (1.5.1) and (1.5.3), it follows that \(P \sim R^m\) and \(Q \sim R^n\text{.}\)
    🔗
    🔗

    Remark 1.5.2.

    A polynomial \(R \in K[x,y]\setminus K\) is said to be not a proper power if \(R \sim S^i\) implies \(i = 1\text{.}\) For every polynomial \(P \in K[x,y]\setminus K\text{,}\) there exists a polynomial \(R\text{,}\) which is not a proper power, and a natural number \(n\) such that \(P \sim R^n\text{.}\) Furthermore, if \(P \sim S^m\) for some \(S\text{,}\) then \(m \mid n\text{;}\) and the following conditions are equivalent:
    🔗
    1. \(S\) is not a proper power,
      🔗
    2. \(R \sim S\text{,}\)
      🔗
    3. \(m = n\text{,}\)
      🔗
    4. \(m\) is the largest integer for which there exists \(S \in K[x,y]\) such that \(P \sim S^m\text{.}\)
      🔗
    Clearly, in Proposition 1.5.1(2b) we can take \(R\) not a proper power, but then we lose the property that \(\gcd(m,n) = 1\text{.}\)

    Lemma 1.5.3.

    Let \((\rho,\sigma) \in \mathfrak{V}\) and let \((P,Q)\) be a Jacobian pair. If \(v_{\rho\sigma}(P) \ne 0\text{,}\) then there exists \(G_0 \in K[P,Q]\) such that
    \begin{equation*} [\ell_{\rho\sigma}(G_0), \ell_{\rho\sigma}(P)] \ne 0 \quad\text{and}\quad [[\ell_{\rho\sigma}(G_0), \ell_{\rho\sigma}(P)], \ell_{\rho\sigma}(P)] = 0. \end{equation*}
    Moreover, if we define recursively \(G_i := [G_{i-1}, P]\text{,}\) then \([\ell_{\rho\sigma}(G_i), \ell_{\rho\sigma}(P)] = 0\text{,}\) for \(i \ge 1\text{.}\)
    🔗
    🔗

    Proof.
    For \(t \in \mathbb{N}\text{,}\) set
    \begin{equation*} \mathfrak{M}(t) := \operatorname{linspan} \{P^i Q^j : 0 \le i,j \le t\}. \end{equation*}
    Since \(\{P^i Q^j : 0 \le i,j \le t\}\) is linearly independent (by Remark 1.2.18), we have
    \begin{equation} \dim \mathfrak{M}(t) = (t+1)^2.\tag{1.5.5} \end{equation}
    On the other hand, by items 4 and 5 of Remark 1.4.9, we know that
    \begin{equation*} mt \le -v_{-\rho,-\sigma}(z) \le v_{\rho\sigma}(z) \le Mt \quad\text{for each } z \in \mathfrak{M}(t) \setminus \{0\}, \end{equation*}
    where
    \begin{align*} m &:= \min\{0, -v_{-\rho,-\sigma}(P), -v_{-\rho,-\sigma}(Q), -v_{-\rho,-\sigma}(P) - v_{-\rho,-\sigma}(Q)\} \end{align*}
    and
    \begin{align*} M &:= \max\{0, v_{\rho\sigma}(P), v_{\rho\sigma}(Q), v_{\rho\sigma}(P) + v_{\rho\sigma}(Q)\}. \end{align*}
    In other words,
    \begin{equation*} J_t := v_{\rho\sigma}(\mathfrak{M}(t) \setminus \{0\}) \subseteq \mathbb{Z} \cap [mt, Mt]. \end{equation*}
    For each \(\beta \in J_t\text{,}\) we take a \(z_{\beta} \in \mathfrak{M}(t)\) with \(v_{\rho\sigma}(z_{\beta}) = \beta\text{.}\) We next prove that, for some \(t \in \mathbb{N}\) sufficiently large, there exists \(H \in \mathfrak{M}(t)\) such that
    \begin{equation} [\ell_{\rho\sigma}(P), \ell_{\rho\sigma}(H)] \ne 0.\tag{1.5.6} \end{equation}
    Assume by contradiction that
    \begin{equation*} [\ell_{\rho\sigma}(P), \ell_{\rho\sigma}(H)] = 0 \qquad\text{for all } t \in \mathbb{N} \text{ and all } H \in \mathfrak{M}(t). \end{equation*}
    We claim that then
    \begin{equation} \mathfrak{M}(t) = \operatorname{linspan}\{z_{\beta} : \beta \in J_t\} \quad \text{for all } t \in \mathbb{N}.\tag{1.5.7} \end{equation}
    In fact, suppose this equality is false for some \(t\text{,}\) and choose \(z \in \mathfrak{M}(t) \setminus \operatorname{linspan} \{z_{\beta} : \beta \in J_t\}\) such that the number \(\gamma := v_{\rho\sigma}(z)\) is minimum. By assumption,
    \begin{equation*} [\ell_{\rho\sigma}(P), \ell_{\rho\sigma}(z)] = [\ell_{\rho\sigma}(P), \ell_{\rho\sigma}(z_{\gamma})] = 0. \end{equation*}
    Since \(v_{\rho\sigma}(P) \ne 0\text{,}\) by Proposition 1.5.1(2b) and Remark 1.5.2, there exist \(\lambda, \lambda_{\gamma} \in K^{\times}\text{,}\) \(n, n_{\gamma} \in \mathbb{N}_0\) and a polynomial \(R\text{,}\) which is not a proper power, such that
    \begin{equation*} \ell_{\rho\sigma}(z) = \lambda R^n \quad\text{and}\quad \ell_{\rho\sigma}(z_{\gamma}) = \lambda_{\gamma} R^{n_{\gamma}}. \end{equation*}
    But, since \(v_{\rho\sigma}(z) = v_{\rho\sigma}(z_{\gamma})\) and \(v_{\rho\sigma}(R) \ne 0\text{,}\) by Remark 1.4.9(4), we have \(n = n_{\gamma}\text{.}\) Hence,
    \begin{equation*} v_{\rho\sigma}(z - \lambda \lambda_{\gamma}^{-1} z_{\gamma}) < v_{\rho\sigma}(z) \quad\text{and}\quad z - \lambda \lambda_{\gamma}^{-1} z_{\gamma} \in \mathfrak{M}(t) \setminus \operatorname{linspan}\{z_{\beta} : \beta \in J_t\}, \end{equation*}
    which contradicts the choice of \(z\) and thus proves (1.5.7), finishing the proof of the claim. But (1.5.7) implies \(\dim \mathfrak{M}(t) \le |J_t| \le (M - m)t\text{,}\) for all \(t\text{,}\) which contradicts (1.5.5) if we take \(t \ge M - m\text{.}\) Thus, we can find \(H \in K[P,Q]\) such that (1.5.6) is satisfied. We now define recursively \((H_j)_{j\ge 0}\text{,}\) by setting
    \begin{equation*} H_0 := H \quad\text{and}\quad H_{j+1} := [H_j, P]. \end{equation*}
    Since \(H_0 \in K[P,Q]\) and \([P,Q] \in K^{\times}\text{,}\) from Remark 1.2.18 it follows that eventually \(H_l = 0\text{.}\) Let \(k\) be the largest index for which \(H_k \ne 0\text{.}\) By Remark 1.4.11(3), we know that \([\ell_{\rho\sigma}(H_k), \ell_{\rho\sigma}(P)] = 0\text{.}\) But we also have \([\ell_{\rho\sigma}(H_0), \ell_{\rho\sigma}(P)] \ne 0\) and so there exists a largest \(j\) such that \([\ell_{\rho\sigma}(H_j), \ell_{\rho\sigma}(P)] \ne 0\text{.}\) Hence, by Proposition 1.4.12, we have \([\ell_{\rho\sigma}(H_j), \ell_{\rho\sigma}(P)] = \ell_{\rho\sigma}(H_{j+1})\text{.}\) Thus
    \begin{equation*} [[\ell_{\rho\sigma}(H_j), \ell_{\rho\sigma}(P)], \ell_{\rho\sigma}(P)] = [\ell_{\rho\sigma}(H_{j+1}), \ell_{\rho\sigma}(P)] = 0, \end{equation*}
    and so \(G_0 := H_j\) satisfies the required conditions.

    Proposition 1.5.4.

    Let \((\rho,\sigma) \in \mathfrak{V}\text{,}\) let \((P,Q)\) be a Jacobian pair and let \(R \in K[x,y]\) be a polynomial such that \(\ell_{\rho\sigma}(P) \sim R^t\) with \(t > 0\) as large as possible. If \(v_{\rho\sigma}(P) \ne 0\text{,}\) then there exists \(k \ge 0\) and a \((\rho,\sigma)\)-homogeneous element \(F_0 \in K[x,y]\) such that \([R, F_0] \sim R^k\text{.}\)
    🔗
    🔗

    Proof.
    Let \(G_0\) be as in Lemma 1.5.3 and set \(F_0 := \ell_{\rho\sigma}(G_0) \ne 0\) and \(F_1 := [F_0, R]\text{.}\) Since
    \begin{equation*} [\ell_{\rho\sigma}(G_0), \ell_{\rho\sigma}(P)] \sim [F_0, R^t] = t R^{t-1} [F_0, R] \sim R^{t-1} F_1 \end{equation*}
    and
    \begin{equation*} [[\ell_{\rho\sigma}(G_0), \ell_{\rho\sigma}(P)], \ell_{\rho\sigma}(P)] \sim [R^{t-1} F_1, R^t] = t R^{2t-2} [F_1, R], \end{equation*}
    by Lemma 1.5.3, we have \(F_1 \ne 0\) and \([F_1, R] = 0\text{.}\) Thus, since \(v_{\rho\sigma}(R) = \frac{1}{t} v_{\rho\sigma}(P) \ne 0\text{,}\) we can apply Proposition 1.5.1(2b), and we obtain that \(F_1 \sim S^k\) and \(R \sim S^i\text{,}\) for some \(i,k \ge 0\) and some \((\rho,\sigma)\)-homogeneous element \(S \in K[x,y]\text{.}\) Note that \(i > 0\) because \(v_{\rho\sigma}(R) \ne 0\text{.}\) But, since \(t\) is maximal, we must have \(i = 1\text{,}\) and so \(S \sim R\text{.}\) Hence \(F_1 \sim R^k\text{,}\) as desired.
    🔗
    🔗

    Proposition 1.5.5.

    Let \((\rho,\sigma) \in \mathfrak{V}_{>0}\) and let \(R,F \in K[x,y]\setminus\{0\}\) be \((\rho,\sigma)\)-homogeneous elements. Assume that \(v_{\rho\sigma}(R) \ge 0\) and that there exists \(k \ge 1\) such that
    \begin{equation} [R,F] = R^k.\tag{1.5.8} \end{equation}
    Define \(z := x^{-\sigma} y^{\rho} \in K[x,y,x^{-1},y^{-1}]\text{,}\) and write
    \begin{equation} R = x^i y^j r(z) \quad\text{and}\quad F = x^u y^v f(z), \quad \text{with } r(z), f(z) \in K[z],\; f(0) \ne 0,\; r(0) \ne 0.\tag{1.5.9} \end{equation}
    Then
    🔗
    1. \(v_{\rho\sigma}(F) = (k-1) v_{\rho\sigma}(R) + \rho + \sigma\text{.}\)
      🔗
    2. Every irreducible factor of \(r(z)\) divides \(f(z)\text{.}\)
      🔗
    3. If \(f(z)\) is a constant (i.e., \(F\) is a monomial), then \(r(z)\) is also a constant (i.e., \(R\) is a monomial).
      🔗
    4. If \(\deg(f(z)) = 1\text{,}\) then \(r(z) \sim (z - \lambda)^{\ell}\text{,}\) for some \(\lambda \in K^{\times}\) and \(\ell \in \mathbb{N}_0\text{.}\)
      🔗
    5. \begin{equation} R^k = x^{i+u-1} y^{j+v-1} \left( v_{\rho\sigma}(R) z r(z) f'(z) - v_{\rho\sigma}(F) z f(z) r'(z) + (iv - ju) r(z) f(z) \right).\tag{1.5.10} \end{equation}
      🔗
    🔗

    Proof.
    Since \(F\) and \(R\) are \((\rho,\sigma)\)-homogeneous, by Remark 1.4.11(1) and Remark 1.4.9(4) we have
    \begin{equation*} v_{\rho\sigma}(R) + v_{\rho\sigma}(F) - (\rho+\sigma) = k v_{\rho\sigma}(R), \end{equation*}
    which yields item 1. By (1.5.8), (1.5.9) and Lemma 1.2.17, we obtain that
    \begin{equation} \tag{1.5.11} \end{equation}
    On the other hand, by (1.4.3) we have
    \begin{equation*} \operatorname{stn}_{\rho\sigma}(R) = (i,j) \quad\text{and}\quad \operatorname{stn}_{\rho\sigma}(F) = (u,v). \end{equation*}
    Hence
    \begin{equation*} v_{\rho\sigma}(R) = v_{\rho\sigma}(\operatorname{stn}_{\rho\sigma}(R)) = v_{\rho\sigma}(i,j) = \rho i + \sigma j \quad\text{and}\quad v_{\rho\sigma}(F) = \rho u + \sigma v, \end{equation*}
    and so, by (1.2.2) we have
    \begin{gather*} [x^i y^j, x^u y^v] = (iv - ju) x^{i+u-1} y^{j+v-1},\\ [x^i y^j, z] = [x^i y^j, x^{-\sigma} y^{\rho}] = (i\rho + j\sigma) x^{i-\sigma-1} y^{j+\rho-1} = v_{\rho\sigma}(R) z x^{i-1} y^{j-1},\\ [z, x^u y^v] = [x^{-\sigma} y^{\rho}, x^u y^v] = -(\sigma v + \rho u) x^{u-\sigma-1} y^{v+\rho-1} = -v_{\rho\sigma}(F) z x^{u-1} y^{v-1}. \end{gather*}
    Inserting these values into (1.5.11), we obtain
    \begin{equation*} R^k = x^{i+u-1} y^{j+v-1} \left( v_{\rho\sigma}(R) z r(z) f'(z) - v_{\rho\sigma}(F) z f(z) r'(z) + (iv - ju) r(z) f(z) \right), \end{equation*}
    which is item 5. Let \(h(z)\) be an irreducible factor of \(r(z)\) and let \(m\) and \(n\) be the multiplicity of \(h(z)\) in \(r(z)\) and \(f(z)\text{,}\) respectively. Note that \(h(z) \ne z\text{,}\) since \(r(0) \ne 0\text{.}\) We claim that \(n > 0\text{.}\) In fact, since \(k \ge 1\text{,}\) by item 1 we have \(v_{\rho\sigma}(F) \ne 0\text{.}\) Consequently, if \(n = 0\text{,}\) then computing the multiplicity of \(h(z)\) in each side of (1.5.10), we obtain that \(k m = m - 1\text{,}\) which is impossible. This proves item 2. Items 3 and 4 follow directly from item 2, which concludes the proof.

    Theorem 1.5.6.

    Let \((\rho,\sigma) \in \mathfrak{V}_{>0}\) and let \((P,Q)\) be a Jacobian pair. If \(v_{\rho\sigma}(P) > 0\text{,}\) then there exists a \((\rho,\sigma)\)-homogeneous element \(F \in K[x,y]\) such that
    \begin{equation} [\ell_{\rho\sigma}(P), F] \sim \ell_{\rho\sigma}(P).\tag{1.5.12} \end{equation}
    Moreover
    🔗
    1. \(v_{\rho\sigma}(F) = \rho + \sigma\text{,}\)
      🔗
    2. \(\operatorname{stn}_{\rho\sigma}(P) \times \operatorname{stn}_{\rho\sigma}(F) \ne 0\) if and only if \(\operatorname{stn}_{\rho\sigma}(F) = (1,1)\text{,}\)
      🔗
      🔗
    3. \(\operatorname{en}_{\rho\sigma}(P) \times \operatorname{en}_{\rho\sigma}(F) \ne 0\) if and only if \(\operatorname{en}_{\rho\sigma}(F) = (1,1)\text{,}\)
      🔗
      🔗
    4. \(\operatorname{stn}_{\rho\sigma}(P) \times (1,1) \ne 0\) and \(\operatorname{en}_{\rho\sigma}(P) \times (1,1) \ne 0\text{,}\)
      🔗
      🔗
    🔗

    Proof.
    Let \(R \in K[x,y]\) be such that \(\ell_{\rho\sigma}(P) \sim R^t\) with \(t > 0\) as large as possible. Clearly \(R\) is \((\rho,\sigma)\)-homogeneous. Moreover, by Proposition 1.5.4, there exist a \((\rho,\sigma)\)-homogeneous element \(F_0 \in K[x,y]\) and \(k \ge 0\) such that \([R, F_0] \sim R^k\text{.}\) We can and will assume that
    \begin{equation} [R, F_0] = R^k.\tag{1.5.13} \end{equation}
    Note that
    \begin{equation} v_{\rho\sigma}(R) = \frac{1}{t} v_{\rho\sigma}(P) > 0\tag{1.5.14} \end{equation}
    and that, by Proposition 1.5.5(1) and Remark 1.4.9(4),
    \begin{equation*} v_{\rho\sigma}(F_0) = (k-1) v_{\rho\sigma}(R) + \rho + \sigma > 0. \end{equation*}
    Hence \((0,0) \notin \{\operatorname{stn}_{\rho\sigma}(F_0),\, \operatorname{en}_{\rho\sigma}(F_0),\, \operatorname{stn}_{\rho\sigma}(P),\, \operatorname{en}_{\rho\sigma}(P)\}\text{.}\) Next, we will prove that there exists a \((\rho,\sigma)\)-homogeneous element \(F \in K[x,y]\) such that
    \begin{equation} [R, F] = R.\tag{1.5.15} \end{equation}
    If \(k = 0\text{,}\) we can take \(F := F_0 R\text{.}\) So, we can assume that \(k \ge 1\text{.}\) In this case, we will prove that there exists a \((\rho,\sigma)\)-homogeneous element \(F \in K[x,y]\) such that
    \begin{equation} F_0 = F R^{k-1}.\tag{1.5.16} \end{equation}
    This will finish the proof of (1.5.15), because it implies that
    \begin{equation*} R^{k-1}[R, F] = [R, F R^{k-1}] = [R, F_0] = R^k, \end{equation*}
    and, since \(K[x,y]\) is a domain, we obtain \([R, F] = R\text{.}\) Set \(z := x^{-\sigma} y^{\rho}\) and write
    \begin{equation} R = x^i y^j r(z) \quad\text{and}\quad F_0 = x^u y^v f(z), \quad \text{with } r(z), f(z) \in K[z],\; f(0) \ne 0,\; r(0) \ne 0.\tag{1.5.17} \end{equation}
    By Proposition 1.5.5(5), we have
    \begin{equation} R^k = x^{i+u-1} y^{j+v-1} \left( v_{\rho\sigma}(R) z r(z) f'(z) - v_{\rho\sigma}(F_0) z f(z) r'(z) + (iv - ju) r(z) f(z) \right).\tag{1.5.18} \end{equation}
    Let \(h(z)\) be an irreducible factor of \(r(z)\) and let \(m\) and \(n\) be the multiplicity of \(h(z)\) in \(r(z)\) and \(f(z)\text{,}\) respectively. By Proposition 1.5.5(2) we know that \(n > 0\text{.}\) Next we will prove that \(n > (k-1)m\text{.}\) For this, we write \(r(z) = h(z)^m \overline{r}(z)\) and \(f(z) = h(z)^n \overline{f}(z)\text{.}\) Then
    \begin{equation*} r'(z) = h(z)^m \overline{r}'(z) + m h(z)^{m-1} h'(z) \overline{r}(z) \quad\text{and}\quad f'(z) = h(z)^n \overline{f}'(z) + n h(z)^{n-1} h'(z) \overline{f}(z), \end{equation*}
    and so (1.5.18) yields
    \begin{align*} R^k &= x^{u+i-1} y^{v+j-1} \Biggl( v_{\rho\sigma}(R) z h(z)^m \overline{r}(z) \left( h(z)^n \overline{f}'(z) + n h(z)^{n-1} h'(z) \overline{f}(z) \right)\\ &\qquad - v_{\rho\sigma}(F_0) z h(z)^n \overline{f}(z) \left( h(z)^m \overline{r}'(z) + m h(z)^{m-1} h'(z) \overline{r}(z) \right) + (iv - ju) h(z)^{m+n} \overline{r}(z) \overline{f}(z) \Biggr)\\ &= x^{u+i-1} y^{v+j-1} \Biggl( h(z)^{n+m-1} \overline{f}(z) \overline{r}(z) h'(z) z \left( v_{\rho\sigma}(R) n - v_{\rho\sigma}(F_0) m \right)\\ &\qquad + h(z)^{m+n} \Bigl( v_{\rho\sigma}(R) z \overline{r}(z) \overline{f}'(z) - v_{\rho\sigma}(F_0) z \overline{r}'(z) \overline{f}(z) + (iv - ju) \overline{r}(z) \overline{f}(z) \Bigr) \Biggr). \end{align*}
    The multiplicity of \(h(z)\) on the left hand side is \(mk\text{.}\) If \(v_{\rho\sigma}(R) n - v_{\rho\sigma}(F_0) m \ne 0\text{,}\) then the multiplicity of \(h(z)\) on the right hand side is \(m + n - 1\text{,}\) and so \(mk = m + n - 1\text{,}\) which implies \(n = m(k-1) + 1 > m(k-1)\text{,}\) as desired. If \(v_{\rho\sigma}(R) n - v_{\rho\sigma}(F_0) m = 0\text{,}\) then, using item 1 of Proposition 1.5.5 and that \(\rho+\sigma > 0\text{,}\) we obtain
    \begin{equation*} v_{\rho\sigma}(R) n = v_{\rho\sigma}(F_0) m = m(k-1) v_{\rho\sigma}(R) + m(\rho+\sigma) > m(k-1) v_{\rho\sigma}(R). \end{equation*}
    Since \(v_{\rho\sigma}(R) > 0\text{,}\) this implies that \(n > m(k-1)\text{,}\) also in this case. Since this is true for each irreducible factor of \(r(z)\text{,}\) there exists \(g(z) \in K[z]\text{,}\) such that \(f(z) = r(z)^{k-1} g(z)\text{.}\) But then
    \begin{equation*} x^{i(k-1)} y^{j(k-1)} F_0 = x^{i(k-1)+u} y^{j(k-1)+v} f(z) = x^{i(k-1)+u} y^{j(k-1)+v} r(z)^{k-1} g(z) = x^u y^v g(z) R^{k-1}, \end{equation*}
    and so
    \begin{equation*} F := x^{u - i(k-1)} y^{v - j(k-1)} g(z) \in K[x,y,x^{-1},y^{-1}] \end{equation*}
    satisfies (1.5.16). We claim that \(F \in K[x,y]\text{.}\) Write \(g(z) = \sum_{\ell=0}^{\gamma} b_{\ell} z^{\ell}\) with \(b_{\gamma} \ne 0\text{.}\) Since
    \begin{equation*} F = x^{u - i(k-1)} y^{v - j(k-1)} \sum_{\ell=0}^{\gamma} b_{\ell} z^{\ell} = x^{u - i(k-1)} y^{v - j(k-1)} \sum_{\ell=0}^{\gamma} b_{\ell} x^{-\sigma \ell} y^{\rho \ell}, \end{equation*}
    in order to prove the claim, we must show that
    \begin{equation} u - i(k-1) - \sigma \ell \ge 0 \quad\text{and}\quad v - j(k-1) + \rho \ell \ge 0, \qquad \text{for } 0 \le \ell \le \gamma.\tag{1.5.19} \end{equation}
    Clearly, for this will be sufficient to prove the cases \(\ell = 0\) and \(\ell = \gamma\text{.}\) We first show that \(u - i(k-1) \ge 0\) and \(v - j(k-1) \ge 0\text{.}\) If \(\operatorname{stn}_{\rho\sigma}(R) \times \operatorname{stn}_{\rho\sigma}(F_0) \ne 0\text{,}\) then, by equality (1.5.13), Proposition 1.4.23(1) and Remark 1.4.14, we have
    \begin{equation*} \operatorname{stn}_{\rho\sigma}(R) + \operatorname{stn}_{\rho\sigma}(F_0) - (1,1) = k \operatorname{stn}_{\rho\sigma}(R). \end{equation*}
    Since, by (1.5.17) and (1.4.3) we know that \(\operatorname{stn}_{\rho\sigma}(F_0) = (u,v)\) and \(\operatorname{stn}_{\rho\sigma}(R) = (i,j)\text{,}\) this equation is equivalent to
    \begin{equation*} \bigl( u - (k-1)i,\; v - (k-1)j \bigr) = (1,1). \end{equation*}
    Consequently,
    \begin{equation*} u - i(k-1) = 1 \ge 0 \quad\text{and}\quad v - j(k-1) = 1 \ge 0, \end{equation*}
    as desired. On the other hand, if \(\operatorname{stn}_{\rho\sigma}(R) \times \operatorname{stn}_{\rho\sigma}(F_0) = 0\text{,}\) then
    \begin{equation} \operatorname{stn}_{\rho\sigma}(F_0) = \lambda \operatorname{stn}_{\rho\sigma}(R), \quad \text{for some } \lambda \in \mathbb{Q}^{\times},\tag{1.5.20} \end{equation}
    and so,
    \begin{equation*} \bigl( u - (k-1)i,\; v - (k-1)j \bigr) = \operatorname{stn}_{\rho\sigma}(F_0) - (k-1) \operatorname{stn}_{\rho\sigma}(R) = (\lambda - k + 1) \operatorname{stn}_{\rho\sigma}(R). \end{equation*}
    Moreover, by (1.5.20), we have \(v_{\rho\sigma}(F_0) = \lambda v_{\rho\sigma}(R)\text{,}\) which combined with (1.5.14) and Proposition 1.5.5(1), gives
    \begin{equation*} \lambda = \frac{v_{\rho\sigma}(F_0)}{v_{\rho\sigma}(R)} = k-1 + \frac{\rho+\sigma}{v_{\rho\sigma}(R)} > k-1. \end{equation*}
    Hence \(u - (k-1)i = (\lambda - (k-1)) i \ge 0\) and \(v - (k-1)j = (\lambda - (k-1)) j \ge 0\text{,}\) as desired. We now prove that
    \begin{equation*} u - i(k-1) - \gamma \sigma \ge 0 \quad\text{and}\quad v - j(k-1) + \gamma \rho \ge 0. \end{equation*}
    Let \(\alpha := \deg(f)\) and \(\beta := \deg(r)\text{.}\) By (1.5.17), (1.4.3) and the fact that \(f(z) = r(z)^{k-1} g(z)\text{,}\) we have
    \begin{equation*} \operatorname{en}_{\rho\sigma}(F_0) = (u,v) + \alpha(-\sigma,\rho), \quad \operatorname{en}_{\rho\sigma}(R) = (i,j) + \beta(-\sigma,\rho) \quad\text{and}\quad \gamma = \alpha - (k-1)\beta. \end{equation*}
    Hence
    \begin{equation} \bigl( u - (k-1)i - \gamma\sigma,\; v - (k-1)j + \gamma\rho \bigr) = \operatorname{en}_{\rho\sigma}(F_0) - (k-1) \operatorname{en}_{\rho\sigma}(R).\tag{1.5.21} \end{equation}
    If \(\operatorname{en}_{\rho\sigma}(R) \times \operatorname{en}_{\rho\sigma}(F_0) \ne 0\text{,}\) then, by equality (1.5.13), Proposition 1.4.23(2) and Remark 1.4.14, we have
    \begin{equation*} \operatorname{en}_{\rho\sigma}(R) + \operatorname{en}_{\rho\sigma}(F_0) - (1,1) = k \operatorname{en}_{\rho\sigma}(R) \iff \bigl( u - (k-1)i - \gamma\sigma,\; v - (k-1)j + \gamma\rho \bigr) = (1,1), \end{equation*}
    where, for the equivalence, we use (1.5.21). Thus
    \begin{equation*} u - i(k-1) - \gamma\sigma = 1 \ge 0 \quad\text{and}\quad v - j(k-1) + \gamma\rho = 1 \ge 0, \end{equation*}
    as desired. On the other hand, if \(\operatorname{en}_{\rho\sigma}(R) \times \operatorname{en}_{\rho\sigma}(F_0) = 0\text{,}\) then
    \begin{equation} \operatorname{en}_{\rho\sigma}(F_0) = \lambda \operatorname{en}_{\rho\sigma}(R), \quad \text{for some } \lambda \in \mathbb{Q}^{\times},\tag{1.5.22} \end{equation}
    and so, again by (1.5.21),
    \begin{equation*} \bigl( u - (k-1)i - \gamma\sigma,\; v - (k-1)j + \gamma\rho \bigr) = \operatorname{en}_{\rho\sigma}(F_0) - (k-1) \operatorname{en}_{\rho\sigma}(R) = (\lambda - k + 1) \operatorname{en}_{\rho\sigma}(R). \end{equation*}
    Moreover, by (1.5.22), we have \(v_{\rho\sigma}(F_0) = \lambda v_{\rho\sigma}(R)\text{,}\) which combined with (1.5.14) and Proposition 1.5.5(1), gives
    \begin{equation*} \lambda = \frac{v_{\rho\sigma}(F_0)}{v_{\rho\sigma}(R)} = k-1 + \frac{\rho+\sigma}{v_{\rho\sigma}(R)} > k-1. \end{equation*}
    Since \((i - \beta\sigma,\; j + \beta\rho) = \operatorname{en}_{\rho\sigma}(R) \in \mathbb{N}_0 \times \mathbb{N}_0\text{,}\) this implies that
    \begin{equation*} u - (k-1)i - \gamma\sigma = (\lambda - k + 1)(i - \beta\sigma) \ge 0 \quad\text{and}\quad v - (k-1)j + \gamma\rho = (\lambda - k + 1)(j + \beta\rho) \ge 0, \end{equation*}
    as desired. This finishes the proof of (1.5.19), and concludes the proof of (1.5.15). But then
    \begin{equation*} [\ell_{\rho\sigma}(P), F] \sim [R^t, F] = t R^{t-1}[R, F] = t R^t \sim \ell_{\rho\sigma}(P), \end{equation*}
    and so (1.5.12) is true. Finally we prove the additional statements. By Remark 1.4.11(1),
    \begin{equation*} [F, \ell_{\rho\sigma}(P)] \sim \ell_{\rho\sigma}(P) \Longrightarrow v_{\rho\sigma}(F) = \rho + \sigma, \end{equation*}
    which is statement 1. Statements 2 and 3 follow from Proposition 1.4.23. In order to prove statement 4, we assume by contradiction that \(\operatorname{stn}_{\rho\sigma}(P) \times (1,1) = 0\text{.}\) By statement 2, necessarily
    \begin{equation} \operatorname{stn}_{\rho\sigma}(F) \ne (1,1),\tag{1.5.23} \end{equation}
    and so, again by statement 2, we have \(\operatorname{stn}_{\rho\sigma}(P) \times \operatorname{stn}_{\rho\sigma}(F) = 0\text{.}\) Since \(\operatorname{stn}_{\rho\sigma}(F) \ne (0,0)\) and \(\operatorname{stn}_{\rho\sigma}(P) \ne (0,0)\) (because \(v_{\rho\sigma}(F) > 0\) and \(v_{\rho\sigma}(P) > 0\)),
    \begin{equation*} \operatorname{stn}_{\rho\sigma}(P) \times \operatorname{stn}_{\rho\sigma}(F) = 0 \quad\text{and}\quad \operatorname{stn}_{\rho\sigma}(P) \times (1,1) = 0 \Longrightarrow \operatorname{stn}_{\rho\sigma}(F) \sim \operatorname{stn}_{\rho\sigma}(P) \sim (1,1). \end{equation*}
    Hence, there exists \(\lambda \in \mathbb{Q}\) such that \(\operatorname{stn}_{\rho\sigma}(F) = \lambda (1,1)\text{.}\) But then \(\lambda = 1\text{,}\) because
    \begin{equation*} \lambda (\rho + \sigma) = v_{\rho\sigma}(\lambda (1,1)) = v_{\rho\sigma}(\operatorname{stn}_{\rho\sigma}(F)) = v_{\rho\sigma}(F) = \rho + \sigma. \end{equation*}
    So \(\operatorname{stn}_{\rho\sigma}(F) = (1,1)\text{,}\) which contradicts (1.5.23) and proves that \(\operatorname{stn}_{\rho\sigma}(P) \times (1,1) \ne 0\text{.}\) By a similar argument we obtain \(\operatorname{en}_{\rho\sigma}(P) \times (1,1) \ne 0\text{,}\) which concludes the proof of item 4 and of the theorem.

    Remark 1.5.7.

    Assume that \((\rho,\sigma)\text{,}\) \(P\) and \(F\) are as in Theorem 1.5.6. Since
    \begin{equation*} v_{\rho\sigma}(P) > 0 \quad\text{and}\quad v_{\rho\sigma}(F) = \rho + \sigma > 0, \end{equation*}
    we know that \((0,0) \notin \{\operatorname{stn}_{\rho\sigma}(F),\, \operatorname{en}_{\rho\sigma}(F), \operatorname{stn}_{\rho\sigma}(P),\, \operatorname{en}_{\rho\sigma}(P)\}\text{.}\) Hence, items 2 and 3 of Theorem 1.5.6 are equivalent to
    \begin{gather*} \operatorname{stn}_{\rho\sigma}(P) \sim \operatorname{stn}_{\rho\sigma}(F) \text{ if and only if } \operatorname{stn}_{\rho\sigma}(F) \ne (1,1) \end{gather*}
    and
    \begin{gather*} \operatorname{en}_{\rho\sigma}(P) \sim \operatorname{en}_{\rho\sigma}(F) \text{ if and only if } \operatorname{en}_{\rho\sigma}(F) \ne (1,1), \end{gather*}
    respectively.
