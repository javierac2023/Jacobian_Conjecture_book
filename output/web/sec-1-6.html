    Section 1.6 Order on directions and shaping the support

    Definition 1.6.1.

    We assign to each direction \((\rho,\sigma)\) its corresponding unit vector in \(S^1\) (that is \(\frac{1}{\|(\rho,\sigma)\|}(\rho,\sigma)\)), and we define an interval in \(\mathfrak{V}\) as the preimage under this map of an arc of \(S^1\) that is not the whole circle. We consider each interval endowed with the order that increases counterclockwise. For example, given \((\rho_1,\sigma_1),(\rho_2,\sigma_2)\in \mathfrak{V}\text{,}\) we let \([(\rho_1,\sigma_1),(\rho_2,\sigma_2)]\) denote the preimage of the arc from \(\frac{1}{\|(\rho_1,\sigma_1)\|}(\rho_1,\sigma_1)\) to \(\frac{1}{\|(\rho_2,\sigma_2)\|}(\rho_2,\sigma_2)\) in the counterclockwise direction, that contains both endpoints. This interval is the set
    \begin{equation*} [(\rho_1,\sigma_1),(\rho_2,\sigma_2)] = \{c \in \mathfrak{V} : (\rho_1,\sigma_1) \le c \le (\rho_2,\sigma_2) \}, \end{equation*}
    where the order is the one mentioned above. In a similar way we can define the open and semiopen intervals \(](\rho_1,\sigma_1),(\rho_2,\sigma_2)[\text{,}\) \(](\rho_1,\sigma_1),(\rho_2,\sigma_2)]\) and \([(\rho_1,\sigma_1),(\rho_2,\sigma_2)[\text{.}\)
    🔗
    🔗

    Definition 1.6.2.

    Let \(P \in K[x,y]\setminus\{0\}\text{.}\) We define the set of directions of \(P\) , as
    \begin{equation*} \operatorname{Dir}(P) := \{(\rho,\sigma) \in \mathfrak{V} : \#\operatorname{Supp}(\ell_{\rho\sigma}(P)) > 1\}. \end{equation*}
    🔗
    🔗

    Definition 1.6.4.

    Let \(P \in K[x,y]\setminus\{0\}\) which is not a monomial and \((\rho,\sigma) \in \mathfrak{V}\text{.}\) We define the successor \(\operatorname{Succ}_P(\rho,\sigma)\) of \((\rho,\sigma)\) to be the first element of \(\operatorname{Dir}(P)\) that one encounters starting from \((\rho,\sigma)\) and running counterclockwise, and the predecessor \(\operatorname{Pred}_P(\rho,\sigma)\text{,}\) to be the first one, if we run clockwise.
    🔗
    🔗

    Remark 1.6.5.

    Note that if \(P \in K[x,y]\setminus\{0\}\) is a monomial, then \(\operatorname{Dir}(P) = \emptyset\) and that if \(P \in K[x,y]\setminus\{0\}\) is \((\rho,\sigma)\)-homogeneous, but is not a monomial, then \(\operatorname{Dir}(P) = \{(\rho,\sigma), (-\rho,-\sigma)\}\text{.}\) In this case
    \begin{equation*} \operatorname{Pred}_P(\rho,\sigma) = \operatorname{Succ}_P(\rho,\sigma) = (-\rho,-\sigma). \end{equation*}
    Furthermore, if \(P \in K[x,y]\setminus\{0\}\) is not homogeneous, then any two consecutive directions of \(P\) are separated by less than \(180^{\circ}\text{,}\) and so \(\operatorname{Pred}_P(\rho,\sigma) \ne \operatorname{Succ}_P(\rho,\sigma)\text{.}\)
    🔗
    🔗

    Remark 1.6.6.

    Let \(P \in K[x,y]\setminus\{0\}\) and let \((\rho_1,\sigma_1)\) and \((\rho_2,\sigma_2)\) be two consecutive directions of \(P\text{.}\) For any direction \((\rho,\sigma)\) with \((\rho_1,\sigma_1) < (\rho,\sigma) < (\rho_2,\sigma_2)\text{,}\) we have
    \begin{equation*} \operatorname{en}_{\rho_1,\sigma_1}(P) = \operatorname{Supp}(\ell_{\rho\sigma}(P)) = \operatorname{stn}_{\rho_2,\sigma_2}(P). \end{equation*}
    🔗
    🔗

    Remark 1.6.7.

    If \(I\) is an interval in \(\mathfrak{V}\text{,}\) smaller than a closed half circle, which means there is no \((\rho,\sigma) \in I\) with \((-\rho,-\sigma) \in I\text{,}\) then, for \((\rho,\sigma), (\rho',\sigma') \in I\text{,}\) we have
    \begin{equation} (\rho,\sigma) < (\rho',\sigma') \Longleftrightarrow (\rho,\sigma) \times (\rho',\sigma') > 0.\tag{1.6.1} \end{equation}
    🔗
    🔗

    Proposition 1.6.8.

    For \(k \in \mathbb{N}_0\) and \(\lambda \in K^{\times}\text{,}\) consider the automorphism \(\varphi\) of \(K[x,y]\) defined by \(\varphi(x) := x\) and \(\varphi(y) := y + \lambda x^k\text{,}\) and set \((\rho,\sigma) := (1,k)\text{.}\) For all \(P \in K[x,y]\setminus\{0\}\) and each direction \((\rho_1,\sigma_1)\) such that \((\rho,\sigma) < (\rho_1,\sigma_1) < (-\rho,-\sigma)\text{,}\) we have
    \begin{equation} \ell_{\rho\sigma}(\varphi(P)) = \varphi(\ell_{\rho\sigma}(P)), \quad \ell_{-\rho,-\sigma}(\varphi(P)) = \varphi(\ell_{-\rho,-\sigma}(P)) \quad\text{and}\quad \ell_{\rho_1,\sigma_1}(\varphi(P)) = \ell_{\rho_1,\sigma_1}(P).\tag{1.6.2} \end{equation}
    Moreover \(\operatorname{en}_{\rho\sigma}(\varphi(P)) = \operatorname{en}_{\rho\sigma}(P)\text{,}\) and so \(v_{\rho\sigma}(\varphi(P)) = v_{\rho\sigma}(P)\text{.}\)
    🔗
    🔗

    Proof.
    Since \(\varphi\) is \((\rho,\sigma)\)-homogeneous (see Example 1.4.26), for all \(P \in K[x,y]\setminus\{0\}\text{,}\) we have
    \begin{equation*} \ell_{\rho\sigma}(\varphi(P)) = \varphi(\ell_{\rho\sigma}(P)) \qquad\text{and}\qquad \ell_{-\rho,-\sigma}(\varphi(P)) = \varphi(\ell_{-\rho,-\sigma}(P)). \end{equation*}
    We next prove that \(\ell_{\rho_1,\sigma_1}(\varphi(P)) = \ell_{\rho_1,\sigma_1}(P)\text{.}\) To begin note that, by Remark 1.6.7,
    \begin{equation*} \sigma_1 - k\rho_1 = (1,k) \times (\rho_1,\sigma_1) = (\rho,\sigma) \times (\rho_1,\sigma_1) > 0, \end{equation*}
    and so \(v_{\rho_1,\sigma_1}(y) = \sigma_1 > k\rho_1 = v_{\rho_1,\sigma_1}(x^k)\text{.}\) Consequently, \(\ell_{\rho_1,\sigma_1}\bigl(y + \lambda x^k\bigr) = y\text{,}\) which implies that
    \begin{equation} \ell_{\rho_1,\sigma_1}\bigl(\varphi(x^i y^j)\bigr) = \ell_{\rho_1,\sigma_1}\bigl(x^i (y + \lambda x^k)^j\bigr) = \ell_{\rho_1,\sigma_1}(x)^i \ell_{\rho_1,\sigma_1}(y + \lambda x^k)^j = x^i y^j,\tag{1.6.3} \end{equation}
    where we use Remark 1.4.9(1). We claim that
    \begin{equation} \ell_{\rho_1,\sigma_1}(\varphi(Q)) = Q \quad \text{for all } (\rho_1,\sigma_1)\text{-homogeneous } Q \in K[x,y]\setminus\{0\}.\tag{1.6.4} \end{equation}
    In fact, let \(Q\) be a \((\rho_1,\sigma_1)\)-homogeneous polynomial. Write \(Q = \sum a_{ij} x^i y^j\text{,}\) where the sum runs on the support of \(Q\text{.}\) By (1.6.3),
    \begin{equation*} v_{\rho_1,\sigma_1}(\varphi(a_{ij}x^i y^j)) = v_{\rho_1,\sigma_1}(\ell_{\rho_1,\sigma_1}(\varphi(a_{ij}x^i y^j))) = v_{\rho_1,\sigma_1}(a_{ij}x^i y^j) = v_{\rho_1,\sigma_1}(Q) \quad \text{for all } a_{ij}. \end{equation*}
    Since, moreover, \(\sum \ell_{\rho_1,\sigma_1}(\varphi(a_{ij}x^i y^j)) = \sum a_{ij} x^i y^j = Q \ne 0\text{,}\) by Remark 1.4.9(2), we obtain (1.6.4). Now write
    \begin{equation*} P = P_1 + P_2 + \cdots + P_r, \quad \text{where each } P_i \text{ is } (\rho_1,\sigma_1)\text{-homogeneous and } v_{\rho_1,\sigma_1}(P_1) > v_{\rho_1,\sigma_1}(P_2) > \cdots. \end{equation*}
    Since, by (1.6.4)
    \begin{equation*} \varphi(P) = \varphi(P_1) + \varphi(P_2) + \cdots + \varphi(P_r) \quad\text{and}\quad v_{\rho_1,\sigma_1}(\varphi(P_i)) = v_{\rho_1,\sigma_1}(\ell_{\rho_1,\sigma_1}(\varphi(P_i))) = v_{\rho_1,\sigma_1}(P_i), \end{equation*}
    using again (1.6.4) and Remark 1.4.9(3), we obtain
    \begin{equation*} \ell_{\rho_1,\sigma_1}(\varphi(P)) = \ell_{\rho_1,\sigma_1}(\varphi(P_1)) = P_1 = \ell_{\rho_1,\sigma_1}(P), \end{equation*}
    as desired. Now, since \((\rho,\sigma) < (-\sigma,\rho) < (-\rho,-\sigma)\text{,}\) it follows from the first and last equality in (1.6.2), that
    \begin{equation*} \ell_{-\sigma,\rho}(\ell_{\rho\sigma}(\varphi(P))) = \ell_{-\sigma,\rho}(\varphi(\ell_{\rho\sigma}(P))) = \ell_{-\sigma,\rho}(\ell_{\rho\sigma}(P)). \end{equation*}
    Thus, by the second equality in (1.4.2), we have \(\operatorname{en}_{\rho\sigma}(\varphi(P)) = \operatorname{en}_{\rho\sigma}(P)\text{,}\) which concludes the proof.
    🔗
    🔗

    Corollary 1.6.10.

    For \(k \in \mathbb{N}_0\) and \(\lambda \in K^{\times}\text{,}\) consider the automorphism \(\phi \colon K[x,y] \to K[x,y]\text{,}\) defined by \(\phi(x) := x + \lambda y^k\) and \(\phi(y) := y\text{,}\) and set \((\rho,\sigma) := (k,1)\text{.}\) For all \(P \in K[x,y]\setminus\{0\}\) and each direction \((\rho_1,\sigma_1)\) such that \((-\rho,-\sigma) < (\rho_1,\sigma_1) < (\rho,\sigma)\text{,}\) we have
    \begin{equation} \ell_{\rho\sigma}(\phi(P)) = \phi(\ell_{\rho\sigma}(P)), \quad \ell_{-\rho,-\sigma}(\phi(P)) = \phi(\ell_{-\rho,-\sigma}(P)) \quad\text{and}\quad \ell_{\rho_1,\sigma_1}(\phi(P)) = \ell_{\rho_1,\sigma_1}(P).\tag{1.6.5} \end{equation}
    Moreover \(\operatorname{stn}_{\rho\sigma}(\phi(P)) = \operatorname{stn}_{\rho\sigma}(P)\text{,}\) and so \(v_{\rho\sigma}(\phi(P)) = v_{\rho\sigma}(P)\text{.}\)
    🔗
    🔗

    Proof.
    Let \(\varphi := \tau \circ \phi \circ \tau\text{,}\) where \(\tau\) is as in Remark 1.4.16. It is clear that \(\varphi(x) = x\) and \(\varphi(y) = y + \lambda x^k\text{.}\) Hence we can apply the previous proposition in order to obtain
    \begin{gather*} \ell_{\sigma\rho}(\varphi(P)) = \varphi(\ell_{\sigma\rho}(P)), \qquad \ell_{-\sigma,-\rho}(\varphi(P)) = \varphi(\ell_{-\sigma,-\rho}(P)),\\ \ell_{\sigma_1,\rho_1}(\varphi(P)) = \ell_{\sigma_1,\rho_1}(P), \qquad \operatorname{en}_{\sigma\rho}(\varphi(P)) = \operatorname{en}_{\sigma\rho}(P), \end{gather*}
    for all \(P \in K[x,y]\text{.}\) Using Remark 1.4.16, we obtain (1.6.5) and that \(\operatorname{stn}_{\rho\sigma}(\phi(P)) = \operatorname{stn}_{\rho\sigma}(P)\text{.}\) For example
    \begin{equation*} \ell_{\rho\sigma}(\phi(P)) = \ell_{\rho\sigma}(\tau \circ \varphi \circ \tau(P)) = \tau(\ell_{\sigma\rho}(\varphi \circ \tau(P))) = \tau \circ \varphi(\ell_{\sigma\rho}(\tau(P))) = \tau \circ \varphi \circ \tau (\ell_{\rho\sigma}(P)) = \phi(\ell_{\rho\sigma}(P)). \end{equation*}
    We leave the remaining equalities as an exercise for the reader.
    🔗
    🔗

    Remark 1.6.11.

    Let \(\varphi\) be an automorphism of \(K[x,y]\text{.}\) To streamline the exposition from this point onward, we will occasionally refer to the expression \(\varphi(P)\) more informally. Instead of writing it explicitly each time, we may say that we “apply \(\varphi\) to \(P\)” or we “transform \(P\) by \(\varphi\)”. Furthermore, when the context is clear and no ambiguity arises, we may continue to denote the transformed polynomial simply as \(P\text{.}\) This convention will be adopted throughout the remainder of the text.
    🔗
    🔗

    Remark 1.6.12.

    When we apply \(\varphi\) of Proposition 1.6.8, we will sometimes say that \(\varphi\) “cuts”, “extends” or “erases” the edge \(H(\operatorname{Supp}(\ell_{1k}(P)))\text{,}\) or “creates” the edge \(H(\operatorname{Supp}(\ell_{1k}(\varphi(P))))\text{.}\) This has a precise meaning that we will explain. Write
    🔗
    \begin{equation*} \ell_{1k}(P) \sim x^j g(z) \quad \text{with } z := x^{-k}y \text{ and } g(z) \in K[z] \text{ a monic polynomial.} \end{equation*}
    Assume that \(n := \deg(g(z)) > 0\text{.}\) Since \(K\) is algebraically closed,
    \begin{equation*} g(z) = z^{m_0} \prod_{i=1}^r (z - \lambda_i)^{m_i} \quad \text{with } \lambda_1,\dots,\lambda_r \in K^{\times} \text{ all different, } m_0 \in \mathbb{N}_0,\; m_1,\dots,m_r \in \mathbb{N} \text{ and } \sum_{i=0}^r m_i = n. \end{equation*}
    Note that, by the first equality in (1.4.2) and the fact that \(v_{k,-1}(z) = -k^2 - 1 < 0\text{,}\)
    \begin{equation} \operatorname{stn}_{1k}(\ell_{1k}(P)) = (j - k m_0, m_0)\tag{1.6.6} \end{equation}
    and
    \begin{equation} \operatorname{en}_{1k}(\ell_{1k}(P)) = (j - k n, n).\tag{1.6.7} \end{equation}
    Note also that \(\varphi(x) = x\) and \(\varphi(y) = y + \lambda x^k\) implies \(\varphi(z) = z + \lambda\) (we can extend in a unique way \(\varphi\) to an automorphism of \(K[x,x^{-1},y]\text{,}\) which contains \(z\)), and so
    \begin{equation} \ell_{1k}(\varphi(P)) = \varphi(\ell_{1k}(P)) \sim x^j (z + \lambda)^{m_0} \prod_{i=1}^r (z + \lambda - \lambda_i)^{m_i}.\tag{1.6.8} \end{equation}
    We consider the following cases:
    🔗
    \(\textbf{a)}\) \((m_0,r) \ne (0,1)\) and \(\lambda = \lambda_i\text{,}\) for some \(i\) with \(m_i > m_0\text{.}\) By equality (1.6.6) applied to \(\ell_{1k}(\varphi(P))\text{,}\) we have
    \begin{equation*} \operatorname{stn}_{1k}(\varphi(P)) = (j - k m_i, m_i). \end{equation*}
    Since \(v_{01}(\operatorname{stn}_{1k}(\varphi(P))) > v_{01}(\operatorname{stn}_{1k}(P))\text{,}\) we say that \(\varphi\) cuts the edge \(H(\operatorname{Supp}(\ell_{1k}(P)))\text{.}\)
    🔗
    In Figure 1.6.13, we illustrate this case with
    \begin{equation*} k = 2 \quad\text{and}\quad P = 1 + x^8 + x^{10} z (z-1)^2 (z-2), \quad \text{where } z = x^{-2}y. \end{equation*}
    Thus
    \begin{equation*} \ell_{12}(P) = x^{10} z (z-1)^2 (z-2), \quad m_0 = 1 \quad\text{and}\quad m_1 = 2. \end{equation*}
    We take \(\lambda = \lambda_1 = 1\) (so \(\varphi(x) = x\) and \(\varphi(y) = y + x^2\)). A direct computation, using that \(\varphi(z) = z + 1\text{,}\) gives
    \begin{equation*} \varphi(P) = 1 + x^8 + x^{10} z^2 (z+1)(z-1), \end{equation*}
    and so \(\ell_{12}(\varphi(P)) = x^{10} z^2 (z+1)(z-1)\) and \(\operatorname{stn}_{12}(\varphi(P)) = (6,2)\text{.}\)
    🔗
    b) \(m_0 > 0\text{,}\) \(r > 0\) and \(\lambda \notin \{\lambda_1,\dots,\lambda_r\}\) or \(\lambda = \lambda_i\) for some \(i\) with \(m_i < m_0\text{.}\) By equality (1.6.6) applied to \(\ell_{1k}(\varphi(P))\text{,}\) we have
    \begin{equation*} \operatorname{stn}_{1k}(\varphi(P)) = \begin{cases} (j - k m_i, m_i) & \text{if } \lambda = \lambda_i \text{ for some } i, \\ (j, 0) & \text{otherwise.} \end{cases} \end{equation*}
    Since \(v_{01}(\operatorname{stn}_{1k}(\varphi(P))) < v_{01}(\operatorname{stn}_{1k}(P))\text{,}\) we say that \(\varphi\) extends the edge \(H(\operatorname{Supp}(\ell_{1k}(P)))\text{.}\)
    🔗
    In Figure 1.6.14, we illustrate this case with
    \begin{equation*} k = 2 \quad\text{and}\quad P = 1 + x^8 + x^{10} z (z-1)^2 (z-2), \quad \text{where } z = x^{-2}y. \end{equation*}
    Thus
    \begin{equation*} \ell_{12}(P) = x^{10} z (z-1)^2 (z-2) \quad\text{and}\quad m_0 = 1. \end{equation*}
    We take \(\lambda = -1\) (so \(\varphi(x) = x\) and \(\varphi(y) = y - x^2\)). A direct computation, using that \(\varphi(z) = z - 1\text{,}\) gives
    \begin{equation*} \varphi(P) = 1 + x^8 + x^{10} (z-1)(z-2)^2 (z-3), \end{equation*}
    and so \(\ell_{12}(\varphi(P)) = x^{10} (z-1)(z-2)^2 (z-3)\) and \(\operatorname{stn}_{12}(\varphi(P)) = (10,0)\text{.}\)
    🔗
    c) \(m_0 = 0\text{,}\) \(r = 1\) and \(\lambda = \lambda_1\text{.}\) By equalities (1.6.6) and (1.6.7) applied to \(\ell_{1k}(\varphi(P))\text{,}\) we have
    \begin{equation*} \operatorname{stn}_{1k}(\varphi(P)) = \operatorname{en}_{1k}(\varphi(P)) = (j - k n, n). \end{equation*}
    Hence \(\varphi\) erases the edge \(H(\operatorname{Supp}(\ell_{1k}(P)))\text{.}\)
    🔗
    In Figure 1.6.15, we illustrate this case with
    \begin{equation*} k = 2 \quad\text{and}\quad P = 1 + x^6 + x^8 (z-1)^3, \quad \text{where } z = x^{-2}y. \end{equation*}
    Thus \(\ell_{12}(P) = x^8 (z-1)^3\text{.}\) We take \(\lambda = \lambda_1 = 1\) (so \(\varphi(x) = x\) and \(\varphi(y) = y + x^2\)). A direct computation, using that \(\varphi(z) = z + 1\text{,}\) gives
    \begin{equation*} \varphi(P) = 1 + x^6 + x^8 z^3, \end{equation*}
    and so \(\ell_{12}(\varphi(P)) = x^8 z^3\) and \(\operatorname{stn}_{12}(\varphi(P)) = \operatorname{en}_{12}(\varphi(P)) = (2,3)\text{.}\)
    🔗
    d) \(m_0 > 0\text{,}\) \(r = 0\) and \(\lambda \in K^{\times}\text{.}\) By equalities (1.6.6) and (1.6.7) applied to \(\ell_{1k}(\varphi(P))\text{,}\) we have
    \begin{equation*} \operatorname{stn}_{1k}(\varphi(P)) = (j, 0) \ne (j - k m_0, m_0) = \operatorname{en}_{1k}(\varphi(P)). \end{equation*}
    Since \(\ell_{1k}(P)\) is a monomial, we say that \(\varphi\) creates the edge \(H(\operatorname{Supp}(\ell_{1k}(\varphi(P))))\text{.}\)
    🔗
    In Figure 1.6.16, we illustrate this case with
    \begin{equation*} k = 1 \quad\text{and}\quad P = x^2 y + x^3 y + x^2 y^2 + x^3 y^2. \end{equation*}
    Thus \(\ell_{11}(P) = x^3 y^2 = x^5 z^2\text{,}\) where \(z := x^{-1} y\text{.}\) We take \(\lambda = 1\) (so \(\varphi(x) = x\) and \(\varphi(y) = y + x\)). A direct computation, using that \(\varphi(z) = z + 1\text{,}\) gives
    \begin{equation*} \varphi(P) = x^3 (z+1) + x^4 (z+1)(z+2) + x^5 (z+1)^2, \end{equation*}
    and so \(\ell_{11}(\varphi(P)) = x^5 (z+1)^2\) and \(\operatorname{stn}_{12}(\varphi(P)) = (5,0)\text{.}\)
