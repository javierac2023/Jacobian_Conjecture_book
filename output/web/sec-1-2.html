    Section 1.2 The Jacobian determinant and its support

    Definition 1.2.1.

    The (formal) partial derivative of \(P=\sum_{i,j} a_{ij}x^i y^j\) with respect to \(x\) is
    \begin{equation*} \partial_x(P)=P_x=\frac{\partial P}{\partial x} := \sum_{i,j} i a_{ij}x^{i-1} y^j. \end{equation*}
    🔗
    🔗
    For example \(\partial_x(x^3y)=3x^2y\text{,}\) and so \(\operatorname{Supp}(\partial_x(x^3y)) = \{(2,1)\} = \operatorname{Supp}(x^3y)-(1,0)\) (see Figure 1.2.2).
    🔗
    We suspect that \(\operatorname{Supp}(P_x) = \operatorname{Supp}(P)-(1,0)\text{.}\) But, we have \(\partial_x(y)=0\text{,}\) and so,
    \begin{equation*} \operatorname{Supp}(\partial_x(y)) = \emptyset \ne \operatorname{Supp}(y)-(1,0). \end{equation*}
    The correct formula is
    \begin{equation*} \operatorname{Supp}(P_x) = \left(\operatorname{Supp}(P)-(1,0)\right) \cap \mathbb{N}_0^2. \end{equation*}
    🔗

    Definition 1.2.3.

    The partial derivative of \(P=\sum_{i,j} a_{ij}x^i y^j\) with respect to \(y\) is
    \begin{equation*} \partial_y(P)=P_y=\frac{\partial P}{\partial y} := \sum_{i,j} j a_{ij} x^i y^{j-1}. \end{equation*}
    🔗
    🔗
    A similar discussion as above shows that the support of \(P_y\) is given by
    \begin{equation*} \operatorname{Supp}(P_y) = \left(\operatorname{Supp}(P)-(0,1)\right) \cap \mathbb{N}_0^2. \end{equation*}
    For example, if \(P = x^5(y^3+y^2) + x^4(y^4 + y^3 + y^2 + y) + x^3(y^4 + y^3 + y^2 + y + 1)\text{,}\) then
    \begin{gather*} P_x = 5x^4(y^3+y^2) + 4x^3(y^4 + y^3 + y^2 + y) + 3x^2(y^4 + y^3 + y^2 + y + 1) \end{gather*}
    and
    \begin{gather*} P_y = x^5(3y^2+2y) + x^4(4y^3 + 3y^2 + 2y + 1) + x^3(4y^3 + 3y^2 + 2y + 1). \end{gather*}
    We show the supports of \(P\text{,}\) \(P_x\) and \(P_y\) in Figure 1.2.4.
    🔗

    Definition 1.2.8. Polynomial Maps.

    A map \(f\colon K^2 \to K^2\) is called a polynomial map if there exist \(P,Q \in K[x,y]\) such that \(f(a,b) = (P(a,b), Q(a,b))\text{,}\) for all \((a,b) \in K^2\text{.}\) From now on we will name \(f_{P,Q}\) the polynomial map \(f\text{.}\)
    🔗
    🔗

    Definition 1.2.9. Jacobian Matrix.

    The Jacobian matrix of \(f = f_{P,Q}\) is
    \begin{equation*} \operatorname{D} f := \begin{pmatrix} P_x & P_y \\ Q_x & Q_y \end{pmatrix}. \end{equation*}
    We write
    \begin{equation*} [P,Q] = \operatorname{J}(P,Q) := \det \operatorname{D} f = P_x Q_y - P_y Q_x, \end{equation*}
    and call it the Jacobian determinant or simply the Jacobian of \((P,Q)\text{.}\) Moreover, for \(P,Q,R,S \in K[x,y]\text{,}\) we set
    \begin{align*} \operatorname{D} f_{\,\vert (R,S)} := \begin{pmatrix} P_x(R,S) & P_y(R,S) \\ Q_x(R,S) & Q_y(R,S) \end{pmatrix} \end{align*}
    and
    \begin{gather*} \operatorname{J}(P,Q)_{\vert (R,S)} := \det(\operatorname{D} f)_{\vert (R,S)} = P_x(R,S) Q_y(R,S) - P_y(R,S) Q_x(R,S). \end{gather*}
    Note that \(\operatorname{D} f_{\,\vert (x,y)} = \operatorname{D} f\) and \(\operatorname{J}(P,Q)_{\vert (x,y)} = \operatorname{J}(P,Q) = [P,Q]\text{.}\)
    🔗
    🔗
    Since \(\operatorname{Supp}(P_x) \subseteq \operatorname{Supp}(P)-(1,0)\) and \(\operatorname{Supp}(Q_y) \subseteq \operatorname{Supp}(Q)-(0,1)\text{,}\) we have
    \begin{equation*} \operatorname{Supp}(P_x Q_y) \subseteq \operatorname{Supp}(P) + \operatorname{Supp}(Q) - (1,1), \end{equation*}
    and similarly
    \begin{equation*} \operatorname{Supp}(P_y Q_x) \subseteq \operatorname{Supp}(P) + \operatorname{Supp}(Q) - (1,1). \end{equation*}
    🔗
    So,
    \begin{equation} \operatorname{Supp}([P,Q]) \subseteq \operatorname{Supp}(P) + \operatorname{Supp}(Q) - (1,1).\tag{1.2.1} \end{equation}
    Note that one could also use that
    \begin{equation} [x^i y^j, x^k y^l] = (il - jk) x^{i+k-1} y^{j+l-1},\tag{1.2.2} \end{equation}
    in order to obtain the same conclusion. For example, if
    \begin{equation} P = 3xy - y^2 + 3y + 3 \quad\text{and}\quad Q = x^4 y^2 - 3x^4 y - 2x^3 y^2 + 2x^3 y,\tag{1.2.3} \end{equation}
    then
    \begin{equation*} [P,Q] = -6x^4 y^2 + 8x^3 y^3 + 27x^4 y - 30x^3 y^2 - 12x^2 y^3 + 24x^3 y + 30x^2 y^2 - 18x^2 y. \end{equation*}
    So,
    \begin{gather*} \operatorname{Supp}(P) = \{(1,1),(0,2),(0,1),(0,0)\},\quad \operatorname{Supp}(Q) = \{(4,2),(4,1),(3,2),(3,1)\} \end{gather*}
    and
    \begin{gather*} \operatorname{Supp}([P,Q]) = \{(4,2),(3,3),(4,1),(3,2),(2,3),(3,1),(2,2),(2,1)\}. \end{gather*}
    As it is shown in Figure 1.2.10, in this example the inclusion (1.2.1) is strict.
    🔗

    Proposition 1.2.13.

    For each \(P,Q \in K[x,y]\text{,}\) we have \(\operatorname{HN}([P,Q]) \subseteq \operatorname{HN}(P) + \operatorname{HN}(Q) - (1,1)\text{.}\)
    🔗
    🔗

    Proof.
    By identity (1.2.1) and the fact that \(\operatorname{Supp}(P) \subseteq \operatorname{HN}(P)\) and \(\operatorname{Supp}(Q) \subseteq \operatorname{HN}(Q)\text{,}\) we know that
    \begin{equation*} \operatorname{Supp}([P,Q]) \subseteq \operatorname{Supp}(P) + \operatorname{Supp}(Q) - (1,1) \subseteq \operatorname{HN}(P) + \operatorname{HN}(Q) - (1,1). \end{equation*}
    The result follows immediately from this fact, since \(\operatorname{HN}(P) + \operatorname{HN}(Q) - (1,1)\) is a convex set.
    🔗
    🔗
    In Figure 1.2.14, we show that for \(P\) and \(Q\) as in (1.2.3), the inclusion in Proposition 1.2.13 is strict.
    🔗

    Lemma 1.2.17. Basic Properties of the Jacobian.

    For each \(P,Q,H \in K[x,y]\) the following facts hold:
    🔗
    1. \([-,-]\) is a \(K\)-bilinear and alternate form.
      🔗
    2. \([PQ,H] = [P,H]Q + P[Q,H]\text{.}\)
      🔗
    3. \([P^m, Q] = m P^{m-1} [P,Q]\text{,}\) for all \(m \in \mathbb{N}\text{.}\)
      🔗
    4. \([H, PQ] = [H,P]Q + P[H,Q]\text{.}\)
      🔗
    5. \([P, Q^n] = n Q^{n-1} [P,Q]\text{,}\) for all \(n \in \mathbb{N}\text{.}\)
      🔗
    🔗

    Proof.
    Item 1 is straightforward. Items 4 and 5 follow from items 1, 2 and 3. By the Leibniz rule for the partial derivative of a product, we have
    🔗
    \begin{equation*} [PQ,H] = (PQ)_x H_y - (PQ)_y H_x = (P_x Q + P Q_x) H_y - (P_y Q + P Q_y) H_x = [P,H]Q + P[Q,H], \end{equation*}
    which proves that item 2 is true. Item 3 follows by straightforward induction using item 2.
    🔗
    🔗

    Remark 1.2.18. .

    Let \(P\) and \(Q\) in \(K[x,y]\text{.}\) From items 1 and 5 of Lemma Lemma 1.2.17 it follow that
    🔗
    \begin{equation*} [P, P^m] = m P^{m-1}[P,P] = 0 \quad\text{and}\quad [P, Q^n] = n Q^{n-1}[P,Q] \qquad\text{for all } m,n\in \mathbb{N}. \end{equation*}
    Hence, by item 4 of Lemma Lemma 1.2.17,
    🔗
    \begin{equation*} [P, P^m Q^n] = [P,P^m] Q^n + P^m [P, Q^n] = P^m [P, Q^n] = \begin{cases} n P^m Q^{n-1}[P,Q] & \text{if } n>0, \\ 0 & \text{if } n=0. \end{cases} \end{equation*}
    Using this it follows easily that if \([P,Q]\in K^{\times}\text{,}\) then the set \(\{P^i Q^j : i,j\in \mathbb{N}_0\}\) is \(K\)-linearly independent.
    🔗
    🔗
    From now on we will use Lemma Lemma 1.2.17 without explicit mention.
    🔗

    Example 1.2.19.

    Let \(P = x^4 y^2 + 2x^3 y^2 + x^2 y^2\) and \(Q = x^6 y^3 + 3x^5 y^3 + 3x^4 y^3 + x^3 y^3\text{.}\) Then
    🔗
    \begin{equation*} \begin{aligned} P_x &= 4x^3 y^2 + 6x^2 y^2 + 2x y^2, && Q_x = 6x^5 y^3 + 15x^4 y^3 + 12x^3 y^3 + 3x^2 y^3,\\ P_y &= 2x^4 y + 4x^3 y + 2x^2 y, && Q_y = 3x^6 y^2 + 9x^5 y^2 + 9x^4 y^2 + 3x^3 y^2. \end{aligned} \end{equation*}
    A straightforward computation shows that \([P,Q] = P_x Q_y - P_y Q_x = 0\text{.}\) We can verify this equality faster, if we note that for \(R = xy(1+x)\text{,}\) we have \(P = R^2\) and \(Q = R^3\text{.}\) Then, \([P,Q] = [R^2, R^3] = 6 R^3[R,R] = 0\text{.}\) In general, if there exist \(R \in K[x,y]\text{,}\) \(\lambda_P, \lambda_Q \in K\) and \(m,n \in \mathbb{N}_0\text{,}\) such that \(P = \lambda_P R^m\) and \(Q = \lambda_Q R^n\text{,}\) then \([P,Q] = 0\text{.}\) Under certain conditions the reciprocal is true, as we will see in Proposition Lemma 1.2.17.
