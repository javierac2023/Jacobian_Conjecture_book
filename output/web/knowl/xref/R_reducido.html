Remark 1.5.2.

A polynomial \(R \in K[x,y]\setminus K\) is said to be not a proper power if \(R \sim S^i\) implies \(i = 1\text{.}\) For every polynomial \(P \in K[x,y]\setminus K\text{,}\) there exists a polynomial \(R\text{,}\) which is not a proper power, and a natural number \(n\) such that \(P \sim R^n\text{.}\) Furthermore, if \(P \sim S^m\) for some \(S\text{,}\) then \(m \mid n\text{;}\) and the following conditions are equivalent:
🔗
  1. \(S\) is not a proper power,
    🔗
  2. \(R \sim S\text{,}\)
    🔗
  3. \(m = n\text{,}\)
    🔗
  4. \(m\) is the largest integer for which there exists \(S \in K[x,y]\) such that \(P \sim S^m\text{.}\)
    🔗
Clearly, in Proposition 1.5.1(2b) we can take \(R\) not a proper power, but then we lose the property that \(\gcd(m,n) = 1\text{.}\)
