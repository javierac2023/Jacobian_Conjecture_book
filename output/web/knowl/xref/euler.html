Remark 1.4.8.

Since
\begin{equation*} \rho x \frac{\partial x^i y^j}{\partial x} + \sigma y \frac{\partial x^i y^j}{\partial y} = (\rho i + \sigma j) x^i y^j = v_{\rho\sigma}(x^i y^j) x^i y^j, \end{equation*}
a polynomial \(P \ne 0\) is \((\rho,\sigma)\)-homogeneous with \(v_{\rho\sigma}(P) = \tau\) if and only if \(\rho x P_x + \sigma y P_y = \tau P\text{.}\)
