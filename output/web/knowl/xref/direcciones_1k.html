Proposition 1.7.10.

Let \((P,Q)\) be a Jacobian pair in \(K[x,y]\text{,}\) let \((\rho,\sigma) \in ](1,0),(0,1)[ \cap \operatorname{Dir}(P)\) and let \(F\) be as in Theorem 1.5.6. Then the following cases arise:
🔗
  1. If \((\rho,\sigma) = (1,1)\text{,}\) then \(\operatorname{Supp}(F) \subseteq \{(0,2),(1,1),(2,0)\}\text{.}\)
    🔗
    🔗
  2. If \((1,1) < (\rho,\sigma) < (0,1)\text{,}\) then \((\rho,\sigma) = (1,k)\) for some \(k > 1\text{,}\) \(\operatorname{stn}_{\rho\sigma}(F) = (k+1,0)\) and \(\operatorname{en}_{\rho\sigma}(F) = (1,1)\text{.}\)
    🔗
    🔗
  3. If \((1,0) < (\rho,\sigma) < (1,1)\text{,}\) then \((\rho,\sigma) = (k,1)\) for some \(k > 1\text{,}\) \(\operatorname{en}_{\rho\sigma}(F) = (0,k+1)\) and \(\operatorname{stn}_{\rho\sigma}(F) = (1,1)\text{.}\)
    🔗
    🔗
Moreover, if \((\rho,\sigma) \ne (1,1)\) and if we write \(F = x^u y^v f(z)\text{,}\) where \(z = x^{-\sigma} y^{\rho}\) and \((u,v) = \operatorname{stn}_{\rho,\sigma}(F)\text{,}\) then \(f(z)\) has exactly one linear factor (which is different from \(z\text{,}\) since \(f(0) \ne 0\text{,}\) by Remark 1.4.18).
